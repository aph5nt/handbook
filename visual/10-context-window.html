Where you meet it

      
A Claude Code agent harness. The system prompt and the loaded skills carry the rules. Long sessions get compacted, and a rule said only once in a turn can be dropped. An MCP (Model Context Protocol) proxy caps rows so tool results do not flood the window.

    

    

      
The practical choice

      
Rules go first, in the system prompt or a skill. Three good examples beat a page of rules. Tool output is trimmed to the columns the task needs. Pasted documents go in the user or tool slot, marked as data, never in the system slot.
