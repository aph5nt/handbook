Where you meet it

      
Judgement calls with no golden answer: is a wallet a mixer, is a design sound, which root cause fits the logs. Research systems where agents critique each other. A second opinion before a costly or public decision.

    

    

      
The practical choice

      
Give each side a different prompt, or a different model. Make every claim cite evidence the judge can check. Run the judge twice with the order swapped. Keep the arguments for a human. Use debate only for judgement calls: it costs several calls per question.
