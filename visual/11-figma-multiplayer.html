Where you meet it

      
Figma's multiplayer server is written in Rust and holds each open file in memory. Google Docs uses operational transforms with a central server. Notion, Linear and tldraw use similar server-decides syncs. Fully peer-to-peer apps use true CRDTs (conflict-free replicated data types).

    

    

      
The choice you make

      
When a central server already exists, let it order edits: it is simpler than a full CRDT. Merge per property, not per object. Show local edits at once and accept the server's correction. Shard the metadata database behind a proxy so the app code barely changes.
