Where you meet it

      
Cloudflare, Fastly, CloudFront and Akamai, in front of static files and public API answers. Fastly and CloudFront call the shield an origin shield; Cloudflare calls it tiered cache. Per-user and live answers pass straight through to the origin.

    

    

      
The practical choice

      
Hashed URLs for static files, so a deploy needs no purge. Turn the shield on. Purge by tag only what changed. Use s-maxage and stale-while-revalidate to control the edge separately from browsers.
