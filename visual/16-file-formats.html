Where you meet row formats

      
Kafka topics between services: Avro or Protobuf, with a schema registry that checks every new version for compatibility. Each message is one whole record.

    

    

      
Where you meet column formats

      
Lake files for analysis: Parquet or ORC, sorted by the common filter column, read by Spark, Trino and StarRocks. JSON only at the edge, converted on landing.
