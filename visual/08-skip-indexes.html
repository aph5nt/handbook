Skip indexes: rule blocks out, do not find rows

One day of swaps in StarRocks, stored in eight blocks of rows. Each block keeps a tiny summary. Watch the blocks read counter: the job of a skip index is to keep it low.

Where you meet it

      
StarRocks swaps sorted by (pool, block_height): one-pool queries prune blocks. tx_hash lookups on a table sorted by height: declare a bloom filter on tx_hash. dex_name = 'aerodrome' AND token = 'WETH': two bitmaps and one AND.

    

    

      
The practical choice

      
Choose the sort key from the filters people run, so zone maps skip. Add a bloom filter for equality on an unsorted column, a bitmap for a column with few values, and an inverted index for terms in text or arrays.
