Prefetch count

A RabbitMQ worker can hold several unacknowledged messages at once. That number is the prefetch count. Tiny metric pings and heavy resize jobs need very different values. Press Next to see a worker starve with prefetch 1, then hoard with prefetch 100.

Where you meet it

      
RabbitMQ's basic.qos sets the prefetch per consumer or channel. SQS has a batch size of 1 to 10 per receive. Kafka's max.poll.records and fetch sizes play the same role for a pull consumer.

    

    

      
The practical choice

      
Start at 1 for slow, heavy jobs, so work spreads fairly and a crash redelivers one job. Start around 100 for tiny, fast messages, so the network round trip is hidden. Then measure: raise it while throughput rises and memory stays flat.
