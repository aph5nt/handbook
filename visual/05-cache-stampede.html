Cache stampede: fifty misses at once

Where you meet it

      
An API in front of a warehouse such as StarRocks, where a dashboard query is cached for one minute and every open tab refreshes together. Also every restart or deploy: the cache is empty and all traffic misses at once. Warm the hot keys before taking traffic.

    

    

      
The practical choice

      
In Go, wrap the loader in singleflight: one call per key in flight, the rest share its result. Add a few percent of random jitter to every TTL. Where users can see a slightly old page, serve stale while one request refreshes in the background.
