Where you meet the outbox

      
Debezium reads the outbox table from the database log and publishes to Kafka, so no application code publishes. An EVM (Ethereum Virtual Machine) indexer writes a block's rows and a "block done" marker in one load, and the graph sync reads the markers. The marker is the outbox.

    

    

      
Where you meet the key

      
Stripe's Idempotency-Key header on every payment call. An indexer table with a primary key on (block, tx_index, log_index), so replaying a block writes the same rows again. Keep keys as long as a retry is possible, often a day.
