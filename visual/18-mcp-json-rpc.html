Where you meet it

      
Every MCP message on every transport. A server written by hand in Go: one struct per shape and a map from id to the waiting caller. A host log: find the failing request's id, then its response.

    

    

      
The practical choice

      
Use a library for the framing. Never reuse an id in a session. Do not build on batches: version 2025-03-26 added them and 2025-06-18 removed them.
