Where you meet it

      
The wallet history page: (from_address, block_height) plus included columns, which also serves keyset pages. A filter with few values, such as status: put it behind a selective column, or partition by it. A column store such as StarRocks has no such index: sort the table by (from_address, block_height) and zone maps do the same job.

    

    

      
The practical choice

      
Equality columns first, the range column last. Include the selected columns only for hot queries, because every extra column makes every write heavier. Test selectivity: an index helps when it picks out a small share of rows.
