Where you meet it: a warehouse API over StarRocks

      
Filters that match the partition and sort key, such as day and address. A filter on any other column is a full scan of a columnar table.

    

    

      
Where you meet it: admin lists and search

      
An admin list over a small table can allow more freedom. A real search need moves to a search engine, not to more query parameters.
