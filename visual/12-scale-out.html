Where you meet it

      
An EVM indexer that walks blocks in ranges scales out: one worker per range, and a dead worker's range is put back on the queue. A graph database with its hot set in RAM scales up: a bigger box with more page cache beats a cluster for read-heavy walks. A Kubernetes autoscaler adds pods on a metric.

    

    

      
The practical choices

      
Make the service stateless before you add a second copy. Keep vertical scaling on the table, because it needs no code change. Pick L7 (application layer) balancing when you route by path or header. Scale an I/O-bound service on queue depth, never on CPU, with a cool-down.
