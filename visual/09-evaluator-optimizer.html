Evaluator-optimizer: write, grade, fix, repeat

A producer writes a Chain Insights answer. An evaluator grades it against a rubric and sends back specific feedback. The producer fixes it. The loop ends when the evaluator passes or a round cap hits. Watch it pass in round 2. Then switch tabs to see vague feedback make the answer worse each round.

Where you meet it

      
A skill improvement loop: run real conversations, grade each against the rules, fix the skill, run again. Code generation with a test suite as the evaluator. Writing tasks with a style rubric. Anthropic lists it among its workflow patterns.

    

    

      
The practical choice

      
Make the evaluator's feedback specific and checkable: which rubric item failed and where. Cap the rounds at two or three. Keep the best-scoring version, not the last one. Use a different prompt or model for the evaluator.
