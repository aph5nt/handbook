Sandboxing: let the agent run code where it cannot hurt

An agent that runs code or shell commands needs a box: a container with only one folder mounted, no secrets, an empty home folder, limited network, and a time limit. Watch a test run inside the box. Then switch tabs to see the same test run against the real home folder.

Where you meet it

      
A test sandbox script that runs every test in a throwaway container with one folder mounted and an empty HOME. Claude Code's sandbox mode and permission rules. E2B, Firecracker micro VMs and gVisor for code interpreters.

    

    

      
The practical choice

      
Run agent code in a throwaway container or micro VM by default. Mount only the work folder, give an empty HOME, no secrets, an allow list for network, and a time and memory limit. Treat the sandbox as the boundary, not the model's good behaviour.
