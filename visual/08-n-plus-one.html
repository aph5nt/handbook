Where you meet it

      
An ORM (Object-Relational Mapper) that loads children lazily: touching order.lines in a loop sends one query per order. A Go indexer writing to StarRocks: one INSERT per row makes one tiny segment per row, and compaction falls behind.

    

    

      
The practical choice

      
Log the query count per request. A count that grows with the result size is N+1. Fix reads with one join, one IN (...) query or eager loading. Fix writes with one bulk load per table per page, sized under the engine's statement limit, with a page id so a retry replaces instead of duplicating.
