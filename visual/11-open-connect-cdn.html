Where you meet it

      
Any heavy static content: video, game downloads, software updates. A CDN (content delivery network) such as CloudFront, Akamai or Cloudflare serves the bytes. The origin keeps only control traffic.

    

    

      
The choice you make

      
Pre-position what you can predict, such as a launch-day download, instead of waiting for the first viewer to pull it. Hand the client a ranked list, so a missing file or a dead box costs distance, not an error.
