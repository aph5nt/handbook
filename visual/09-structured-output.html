Where you meet it

      
OpenAI's strict JSON schema mode, Anthropic's structured outputs and tool input schemas, and grammar-based decoding in llama.cpp and vLLM. A risk verdict in an AML (anti-money-laundering) tool, so a risk kind is never 'probably a mixer'.

    

    

      
The practical choice

      
Use the provider's structured output or a tool schema with enums whenever code reads the answer. Keep a light validator anyway for meaning: the schema guarantees the shape, never the truth. Keep free text for the human-facing explanation, in its own field.
