Where you meet it

      
One app owns its tools in one process: function calling alone is enough. Tools shared across hosts or teams: MCP. The other side has its own model and long-running tasks: A2A. A LangChain tool is a Python object in one process, and LangChain's MCP adapter turns servers into its tools.

    

    

      
The practical choice

      
Wrap an OpenAPI service in an MCP server, but prune: a handful of intent-level tools with descriptions written for a model. Claude, GPT and Gemini hosts can all use the same server, each converting it to its own function-calling format.
