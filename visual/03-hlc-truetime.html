Hybrid logical clocks and TrueTime

A Lamport number like 4,812 means nothing to a human. A hybrid logical clock keeps the wall time and adds a counter. Google's TrueTime gives the time with an error bar instead. Press Next to watch both order events that a plain wall clock gets wrong.

Where you meet HLC

      
CockroachDB and YugabyteDB stamp transactions with a hybrid logical clock and refuse a node whose clock drifts past the maximum offset. MongoDB keeps a hybrid cluster time for causal sessions.

    

    

      
Where you meet TrueTime

      
Spanner. Atomic clocks and GPS receivers in each data centre give every server the time plus a known error, a few milliseconds. Spanner stamps each commit with the latest possible time and waits out the error. That gives strict serializable transactions across the world.
