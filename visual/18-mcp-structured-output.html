Where you meet it

      
A balance or price tool that a script reads. A graph tool whose rows a host draws as a table. A free-text tool needs no output schema.

    

    

      
The practical choice

      
Declare outputSchema when code reads the result. Always add the same JSON as text for older hosts. Snapshot the schema in the contract test.
