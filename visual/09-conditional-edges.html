Conditional edges: code picks the next node

In a state graph, a conditional edge is a small function that reads the state and returns the name of the next node. A screening graph routes a wallet to approve, review or block by its risk score. Watch one wallet take the review branch. Then switch tabs to see a route function that can return a name with no node behind it.

Where you meet it

      
LangGraph add_conditional_edges with a path map. Step Functions Choice states. The Router pattern inside a graph: a cheap classifier or a plain rule in the route function.

    

    

      
The practical choice

      
Keep route functions plain code over the state, not a model call, when a rule will do. Give every route a path map that lists every name it may return, and a default branch. Test the route function on its own with sample states.
