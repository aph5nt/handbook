MCP: one tool server, every host

The Chain Insights proxy is an MCP (Model Context Protocol) server running on the user's machine. Claude Desktop starts it, asks what it offers, and calls its tools. Claude Code plugs into the same server with no new code. Watch the messages. Then switch tabs to see a rule that only some hosts ever read.

Where you meet it

      
The Chain Insights proxy: one MCP server used by Claude Desktop, Claude Code and Codex. IDE (integrated development environment) assistants that list MCP tools from a config file. Any internal tool you want every agent host to reach without writing an adapter per host.

    

    

      
The practical choice

      
Put the rule a host must follow into the tool description, because it is the one text every host reads. Use resources for data read by URI and prompts for user-picked templates. Install only servers you trust, and read their descriptions like code.
