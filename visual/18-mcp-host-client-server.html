Where you meet it

      
Claude Code or Cursor: one config entry per server, one client each. A server that needs another server becomes a host itself, with its own client. Consent, roots and OAuth tokens belong to one client.

    

    

      
The practical choice

      
Keep servers stateless about the conversation. Put per-user state behind the user's own identity, never behind "whoever spoke last".
