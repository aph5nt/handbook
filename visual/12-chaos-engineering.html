Where you meet it

      
Kill the primary database pod on staging and time the failover. Netflix Chaos Monkey kills instances in production during work hours, so engineers build services that shrug it off. Chaos Mesh or Litmus inject pod kills, network delay and full disks on Kubernetes.

    

    

      
The practical choices

      
Define steady state as a user-facing number first. Write the hypothesis down. Start with the smallest blast radius: one pod, staging, a small share of traffic. Agree the abort line and test the abort switch before the fault. Run it as a game day with people watching, then automate what passes.
