Where you meet it

      
Prompt and skill changes in a Claude Code harness: the win rate of the new version over the old, beside the hard checks. Soft quality, such as clarity, tone and usefulness, where no checker exists. Model leaderboards built from people voting on pairs.

    

    

      
The practical choice

      
Write a rubric. Have people label a sample of pairs, then measure how often the LLM (large language model) judge agrees before trusting it at scale. Swap the order and judge twice. Keep facts, like identifiers, in code checks, never in the judge.
