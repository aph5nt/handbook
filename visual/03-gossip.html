Gossip and cluster membership

Node F of a cluster dies. Nobody broadcasts. Each second, each node tells one random peer what it knows. Press Next and watch the news double each round, then watch where gossip is not enough.

Where you meet it

      
Cassandra and Redis Cluster use gossip for membership and node state. Consul uses SWIM gossip for health and Raft for its key-value store: two protocols for two jobs.

    

    

      
The choice you make

      
Use gossip for membership and health, where a view that is a second late hurts nobody. Never use it to elect a leader or grant a lock. Those need an agreed answer, so they need consensus.
