Build an LRU cache

An indexer caches decoded contract ABIs (Application Binary Interfaces, the list of a contract's functions and events), keyed by contract. The cache holds three. When it is full, the least recently used one goes. Two structures work together: a hash map to find, a doubly linked list to keep order.

Where you meet an LRU cache

      
Python functools.lru_cache, and OrderedDict, which is this exact pair inside. Java LinkedHashMap with access order on. An operating system page cache. A decoded-ABI cache in an indexer, keyed by contract address.

    

    

      
The practical choices

      
Under many threads, guard it with a lock or split it into shards, each with its own lock. Add a TTL (time to live) per node when entries go stale. Use LFU (least frequently used) when popular keys must survive a burst of one-off keys.
