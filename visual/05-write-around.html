Where you meet it

      
Bulk imports, backfills, audit and log writes: written once, rarely read soon. Write-heavy tables with few reads, where caching every write only wastes memory.

    

    

      
The practical choice

      
Send cold bulk writes around the cache, straight to the source. Delete any cached copy of a key you write, so no stale copy survives. Accept that the first read after a write is a miss.
