Where you meet it

      
Every Claude Code turn is this loop. The model writes a thought, calls Read or Bash or an MCP tool, gets the result pasted into its context, and thinks again. Chain Insights runs the same loop over graph_query and meta_dex_lookup. LangChain's agent executor and LangGraph's ReAct template are the same loop with different names.

    

    

      
The practical choice

      
Every observation is appended, never removed. A 40 KB tool result stays in the window for the rest of the run. So you cap the result size, you cap the number of iterations, and you refuse a call whose tool and arguments match the previous call. The thought text is output, not a log. Trust the tool results, not the reasoning.
