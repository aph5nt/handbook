Where you meet it

      
A host that connects to servers of many ages: one code path per supported version. A server: support the last two versions while hosts upgrade. A contract test: run the handshake once per version.

    

    

      
The practical choice

      
Propose your newest version, accept what the server answers if you support it, and gate every feature on both the version and the declared capability.
