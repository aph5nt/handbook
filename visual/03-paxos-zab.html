Where you meet it

      
Google Chubby and Spanner run Paxos. ZooKeeper runs ZAB (ZooKeeper Atomic Broadcast), under Kafka's older controller and many Hadoop systems. etcd and Consul run Raft, which is Multi-Paxos made easy to teach.

    

    

      
The choice you make

      
In an interview, explain Raft first. Then say Paxos is the same idea with a harder explanation, and ZAB is ZooKeeper's version with epochs instead of ballots. In a system, run one stable leader so the prepare round happens once, not per value.
