Where you meet it

      
Go's golang.org/x/sync/singleflight in front of a cache loader. Caffeine and groupcache coalesce loads per key by default. CDNs call it request collapsing: one origin request per object.

    

    

      
The practical choice

      
Wrap every expensive loader in singleflight. Give the shared load a timeout and let each caller keep its own deadline. Add a Redis lock across instances only when one query per instance is too many.
