Operators and CRDs

Running a warehouse by hand means many ordered steps. The StarRocks operator turns them into code. Press Next to watch one object become a running warehouse and then upgrade, and to see how one cleanup command can remove it all.

The code that runs this step

The lit lines are the ones the current step runs. Switch between pseudo code and the real thing. The full program, which replays this story and prints the numbers, is in handbook/code/15-operators-crds/main.go (go run .).

Where you meet it: databases

      
StarRocks, Postgres (CloudNativePG) and Kafka (Strimzi) run through operators that know their start order, upgrades and backups.

    

    

      
Where you meet it: small helpers

      
cert-manager is an operator too: a Certificate object becomes a renewed TLS key. Write your own operator only when the product has real procedures to encode.
