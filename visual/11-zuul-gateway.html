Zuul: one front door for every call

Ola's TV asks Netflix to start a film. The request enters through Zuul, the API gateway, where filters check it, route it and send a small share to a canary. Then one slow backend tries to take the whole gateway down. Press Next.

Where you meet it

      
Any public API in front of many services. Kong, Envoy, AWS API Gateway, Spring Cloud Gateway and NGINX play this role. Canary releases are often done here: 1 percent of traffic to the new version, compare, widen.

    

    

      
The choice you make

      
Keep the gateway thin: authentication, routing, limits, metrics. Business logic does not belong there. Give each route a timeout and shed load before the gateway itself runs out of threads or memory.
