Where you meet it

      
A coding agent in a Claude Code harness that runs the tests and retries: pass@k matches how it works. Code benchmarks report pass@1 and pass@10 side by side. A one-shot answer to a person, where nobody runs a test, only pass@1 is honest.

    

    

      
The practical choice

      
Report pass@1 whenever the user gets one try. Report pass@k only when a real checker runs in production and picks the passing sample. Compare models with the same k and the same checker, and estimate from more samples than k, not from one lucky set.
