Where you meet it

      
OpenAI's Swarm and Agents SDK handoffs. Customer-support bots with billing, technical and sales agents. LangGraph's swarm pattern. It suits a conversation that changes topic more than a task that splits into parts.

    

    

      
The practical choice

      
Give each agent a handoff tool whose description says exactly which topics it owns. Pass a short summary with every handoff. Cap handoffs per user turn, and give unclear requests one owner that answers or asks a human.
