Where you meet it

      
OpenTelemetry SDKs (software development kits) in each service, sending spans to a collector, viewed in Jaeger, Tempo or Grafana. The W3C traceparent HTTP header carries the trace id and the parent span id between services. A Go indexer passes the trace context in its context.Context to every StarRocks call.

    

    

      
The practical choices

      
Instrument every client and server with the same library, so the header is passed on without hand-written code. Put the trace id in every log line. Sample at the head when traffic is huge and cost matters. Sample at the tail when you must keep every slow or failed request.
