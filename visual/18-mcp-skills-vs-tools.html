Where you meet it

      
Claude Code, Codex and Desktop Code mode load skill files. Desktop chat and claude.ai load none. A long recipe lives in a skill. An action on outside data is an MCP tool.

    

    

      
The practical choice

      
Put know-how in a skill so it costs tokens only when it fits. Put the must-follow rule in the tool description too. Test that every skill has its door.
