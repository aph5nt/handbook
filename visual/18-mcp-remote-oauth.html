Where you meet it

      
A read-only lookup service: stateless, ten replicas, scaled like any HTTP service. A server with subscriptions or sampling: stateful, with sticky routing or a shared session store, and resumption with Last-Event-ID.

    

    

      
The practical choice

      
Treat the MCP server as a resource server. Use PKCE and a resource indicator. Check the audience on every call. Never pass the user's token through to the APIs behind you. Ask consent per user for each registered client.
