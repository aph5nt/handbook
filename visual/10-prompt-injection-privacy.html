Where you meet it

      
A Claude Code agent harness: hooks check every command before it runs, and the agent holds a short-lived staging credential, never a production write key. Documents, web pages, tool results and other agents' outputs are all untrusted channels.

    

    

      
The practical choice

      
Mark untrusted content and keep it out of the system prompt. Validate structured outputs. Make dangerous actions impossible in code, not discouraged in text. Public chain data may go to a hosted API. A customer's query history is PII (personally identifiable information) territory, so traces stay in-house.
