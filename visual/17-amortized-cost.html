Where you meet amortized cost

      
Go slices, Python lists and Java ArrayList grow by a factor, so append is O(1) amortized. A hash map resize is the same trick. Redis spreads its rehash over many calls, so no single call pays the whole copy.

    

    

      
Bounds in one breath

      
Big-O is at most. Big-Omega (Ω) is at least: any sort that compares items is Ω(n log n). Big-Theta (Θ) is both. Worst, average and best case are different inputs. Amortized is one long run of calls on any input.
