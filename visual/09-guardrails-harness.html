Where you meet it

      
Claude Code hooks run before and after each tool call and can refuse it. A harness test sandbox mounts one work folder and an empty home, added after a test wrote a wallet into a real home folder. An agent holds a short-lived staging token, and production writes go through a reviewed workflow.

    

    

      
The practical choice

      
Write every "never" as code: an allow-list of tools, a hook on dangerous commands, permissions on paths, a sandbox for tools. Send the refusal back with its reason so the agent can choose again. Put a human before an irreversible action, and make the default the reversible one.
