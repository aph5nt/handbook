Expand and contract: change a schema without downtime

A transfers table has a column called dest. The team wants it called to_address. Old and new indexer versions run side by side during a roll. Watch the change done in safe steps, then watch a one-step rename break both versions. Press Next.

Where you meet it

      
Any column rename or type change on a StarRocks or Postgres table that live services write. API (application programming interface) fields: add the new field, move clients, remove the old one. Graph properties: add the new form, migrate, remove the old form in a later step.

    

    

      
The practical choices

      
Make each step its own release, so any one can be rolled back. Backfill in batches, not one giant statement. Switch reads only after the backfill is complete and checked. Put the contract step on the plan with a date, so dead columns do not pile up.
