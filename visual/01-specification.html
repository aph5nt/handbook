Where you meet it

      
Screening and alerting over a StarRocks warehouse, where the same rule both labels one address and selects millions. Entity Framework and LINQ expressions, which translate one C# rule into SQL. Spring Data JPA Specification. Kubernetes label selectors are a small specification language.

    

    

      
The practical choice

      
Use a specification when the same rule appears in more than one place, or when users combine rules. Give each one a business name. Make sure the repository can turn it into a query when the data is big. For a rule used once, a plain method on the entity is enough.
