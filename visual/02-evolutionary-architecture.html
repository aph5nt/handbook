Where you meet it: a repository gate

      
A gate script runs size caps, test-time budgets and import lints on every push. Neal Ford, Rebecca Parsons and Patrick Kua named these fitness functions in "Building Evolutionary Architectures".

    

    

      
Where you meet it: production

      
Holistic fitness functions run against the live system: a latency budget alert, a cost ceiling, a chaos test. Atomic ones check one property in the build.
