Where you meet arrays and lists

      
Pre-size a Go slice when you know n, so it never grows one step at a time. The recency order inside an LRU (least recently used) cache is a doubly linked list, so a node can be unlinked in O(1).

    

    

      
Where you meet queues and stacks

      
A work queue between an indexer's fetch and decode stages is a Go channel: a bounded queue. Breadth-first search uses a queue. The call stack and depth-first search use a stack.

Interview line"An array is fast to index and slow to insert into. A linked list is the opposite, and it misses the processor cache on every hop. A stack is last in first out, a queue is first in first out, and I never pop the front of an array."
