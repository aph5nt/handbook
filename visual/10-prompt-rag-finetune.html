Where you meet it

      
A Claude Code skill carries the answer rules: a prompt kept in git. A knowledge base over runbooks and table docs carries the facts through retrieval. A LoRA (low-rank adaptation) adapter on a small model fits a fixed JSON (JavaScript Object Notation) report shape when the big model is too slow.

    

    

      
The practical choice

      
Prompt first: minutes to try, fully reversible. RAG (retrieval-augmented generation) for facts that change or are private. Fine-tune last, only for style, format or a narrow task, and keep the eval set from before the fine-tune to prove nothing got worse.
