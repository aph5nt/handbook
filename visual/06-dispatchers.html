Where you meet dispatchers

      
Akka and Akka.NET dispatchers, the Erlang schedulers (one per CPU core), the .NET thread pool under Orleans grains. Go goroutines on a few OS (operating system) threads work the same way. The default pool is sized to the CPU cores, because ordinary handlers only compute.

    

    

      
The choice you make

      
Keep handlers short and non-blocking. Call databases and HTTP services asynchronously and pipe the result back as a message. When a driver can only block, give its actors their own dispatcher: a bulkhead, so it can only starve itself.
