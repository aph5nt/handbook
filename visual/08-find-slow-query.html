Where you meet it

      
PostgreSQL pg_stat_statements ordered by total_exec_time. StarRocks audit log grouped by statement digest, sorted by CPU and scan bytes. An APM (application performance monitoring) database view that ties each shape to the service that sent it.

    

    

      
The practical choice

      
Group by shape, sort by total time, explain the top shape with real parameters, fix it, and compare totals. Check the 99th percentile separately for paths a user waits on.
