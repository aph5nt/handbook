Where you meet it: stateless services

      
A query API scales on CPU. A queue worker scales on queue depth (KEDA does this from events). Spot worker pools grow and shrink with the cluster autoscaler.

    

    

      
Where you meet it: writers and sizing

      
A single-writer indexer is never autoscaled; it is split into block ranges. The VPA runs in recommend mode to size requests from real use.
