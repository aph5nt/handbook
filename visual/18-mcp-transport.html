Where you meet stdio

      
A server on the user's own machine. Claude Code, Codex and Claude Desktop spawn it from a config entry. No port, no login: the host owns the process. Logs go to standard error.

    

    

      
Where you meet Streamable HTTP

      
A shared remote service. One POST endpoint, answered with plain JSON or an SSE stream. It sits behind normal HTTP infrastructure and auth. Keep the old HTTP with SSE endpoint only while an old client still needs it.
