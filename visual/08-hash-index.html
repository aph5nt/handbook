Where you meet it

      
PostgreSQL CREATE INDEX ... USING hash for pure equality on long keys. InnoDB builds an adaptive hash index by itself over hot B-tree pages. A hash join and a Redis key lookup run on the same idea.

    

    

      
The practical choice

      
Default to a B-tree. Add a hash index only when every query is exact equality and the key is long. Never for ranges, sorts or prefixes.
