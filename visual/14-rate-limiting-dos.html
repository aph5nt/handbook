Where you meet it

      
Public APIs: per-key limits with clear 429 answers. Login and sign-up: strict limits per account and per address, to slow password guessing.

    

    

      
For agent tool servers

      
A cost limit per query and a timeout, because a model can write a very expensive query by accident and retry it in a loop.
