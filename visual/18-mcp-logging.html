Where you meet it

      
A stdio server: protocol logging or standard error, never standard output. A host debug view: debug while you investigate, warning otherwise. A remote server: protocol logs for the user, server logs for the operator.

    

    

      
The practical choice

      
Log facts the user can act on at warning. Keep detail at debug. Strip tokens, keys and personal data before any log call.
