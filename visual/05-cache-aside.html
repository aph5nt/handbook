Where you meet it

      
Read-heavy lookups: address risk, user profiles, product pages. Any service that holds a Redis client and a database client, and writes the few lines between them itself.

    

    

      
The practical choice

      
Commit first, then delete the key. Delete instead of update, so two writers cannot leave the older value behind. Always keep a TTL, because it ends every race and every failed delete.
