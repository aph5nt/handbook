Where you meet it

      
Any third-party server: pin descriptions and schemas at install. A company gateway: pin once for everyone and alert when an upstream server changes. Your own server: a tools/list snapshot test.

    

    

      
The practical choice

      
Hash the description and the schema together. Re-check on every refresh. Show the user the diff, not only a yes or no.
