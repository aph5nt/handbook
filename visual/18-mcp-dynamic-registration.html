Dynamic client registration

A developer adds a company MCP server to a brand-new host that nobody has set up a client id for. Press Next and watch the host register itself, then an attacker register just as easily.

Where you meet it

      
A public or company MCP server that many different hosts connect to. A closed company tool can use pre-registered client ids and turn registration off.

    

    

      
The practical choice

      
Support registration so new hosts work, then treat each new client as a stranger: consent per client, exact redirects, short-lived tokens.
