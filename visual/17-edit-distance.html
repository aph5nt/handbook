Edit distance: a dynamic programming table

A user types aeor into the exchange search. How many single-letter edits turn it into aero? Fill a table of small answers row by row. Each cell is built from three neighbours already filled.

Where you meet this table

      
Fuzzy name search and spell checkers rank candidates by edit distance. diff and Git compare files with the same table, over lines. DNA alignment and the 0/1 knapsack problem fill the same shape of table with a different rule.

    

    

      
The choice you make

      
Fill a table instead of recursing: O(m × n) instead of exponential. Keep only two rows when you need the distance and not the edits. Use the Damerau variant when typos are mostly swapped letters.
