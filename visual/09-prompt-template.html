Where you meet it

      
LangChain PromptTemplate and ChatPromptTemplate, Jinja templates, f-strings in plain code. Every agent harness keeps its system prompts as templates. Prompt versions are compared in evals like code versions.

    

    

      
The practical choice

      
Keep templates in git and version them. Put every user value inside a clearly marked data block, never in the instructions. Escape literal braces. Render a template in a test with sample values before it ships.
