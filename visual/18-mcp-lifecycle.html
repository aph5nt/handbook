Where you meet the lifecycle

      
Every MCP server in Claude Code, Claude Desktop, Codex or Cursor runs this handshake once per start. A contract test replays it: initialize, initialized, tools/list, one tools/call per tool. That is how you catch a renamed tool or an empty description before any host sees it.

    

    

      
Where you meet the local proxy

      
The Chain Insights proxy runs on the user's laptop over stdio. It keeps the wallet, the cache and small lookups, and forwards heavy graph queries to a remote lane. A new exchange in the lookup is a merged pull request to a public file, not a release.
