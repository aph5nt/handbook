Where tail calls are reused

      
Scheme guarantees it. Scala with @tailrec and Kotlin with tailrec check it. C and C++ compilers often do it with optimisation on, without a promise.

    

    

      
Where they are not

      
Python, Java and Go never reuse the frame. A tail-recursive function there still overflows on deep input, such as a chain of 100,000 blocks. Write the loop: for i := range xs { acc += xs[i] }.
