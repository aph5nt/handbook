Distillation: a small student learns one task from a big teacher

A big model labels addresses well but is slow and costly at a million calls a day. Press Next and watch it teach a small model one task. The second tab shows what happens when the student meets a question outside that task.

The code that runs this step

The lit lines are the ones the current step runs. Switch between pseudo code and real Python. The full program replays this story and prints the same numbers: handbook/code/10-distillation/main.py (python3 main.py). The data is a toy: 20 feature groups and a rule for the true kind.

Where you meet it

      
A high-volume address classifier or router where the big model is too slow or too costly. Model routing, where the distilled student takes the easy, common requests. On-premises serving where only a small model fits on the cards.

    

    

      
The practical choice

      
Distil one narrow task, never general skill. Filter the teacher's answers before training, so its mistakes are not copied. Route only that task to the student. Check that the provider's terms allow training on its outputs.
