Where you meet egress control

      
Any pod holding secrets or customer data: default deny egress. Build agents: only registries and package mirrors.

    

    

      
Where it meets SSRF

      
Webhook senders and URL fetchers go through an egress proxy that also blocks private ranges, which is the SSRF fix.
