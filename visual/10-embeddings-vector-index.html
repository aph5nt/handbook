Where you meet it

      
RAG (retrieval-augmented generation) over runbooks and table docs. A warehouse that holds the documents adds a vector column and an HNSW index, so one system serves facts and similarity. Hybrid search adds keyword search for exact names like core_dex_swaps.

    

    

      
The practical choice

      
Under about a million vectors, flat exact search is often enough. Above that, HNSW for speed and recall if memory allows, IVF when memory is tight. Pin the embedding model version, re-embed everything when it changes, and measure recall on a golden set.
