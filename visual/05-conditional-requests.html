Where you meet it

      
Every CDN revalidates with the origin using these headers. S3 and most object stores return a content hash as the ETag. Edit endpoints where two people can change one record use If-Match.

    

    

      
The practical choice

      
Build the ETag from the content or the row version, never from file time on one server. Send If-None-Match on reads. Require If-Match on updates to shared records, and answer 412 when it does not match.
