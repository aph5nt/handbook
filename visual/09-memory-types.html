Memory types: buffer, summary, vector, entity

An assistant helps one investigator over many days. Four kinds of memory decide what it remembers: a buffer of recent turns, a running summary, a vector store of old turns, and an entity store of facts about addresses. Watch one question use all four. Then switch tabs to see a summary that drops the one fact that mattered.

Where you meet it

      
LangChain's old buffer, summary, vector-store and entity memories, now LangGraph short-term state and long-term stores. Claude Code: the conversation is the buffer, compaction is the summary, CLAUDE.md or AGENTS.md and memory files are the entity store.

    

    

      
The practical choice

      
Keep recent turns whole. Summarise older turns, but pin facts that must never be lost (addresses, decisions, rulings) in an entity store or a file. Use vector recall for old detail the summary dropped. Show the model where each memory came from.
