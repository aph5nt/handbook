Where you meet it

      
MongoDB causal consistency sessions carry an operation time. A page that reads from Postgres replicas stores the leader's log position (LSN, Log Sequence Number) in the user's session after a write. A block explorer remembers the highest block the user has seen.

    

    

      
The choice you make

      
Sticky sessions are simple but break when that replica dies. The robust fix is a position token: the client carries 'I have seen position 41' with every read, and any replica can check itself.
