The N+1 shape

A report page loads 10,000 swaps. For each swap, an object-relational mapper (ORM) quietly loads its pool. The page takes about ten seconds. Count the round trips, then fix it on the second tab.

Where you meet N+1

      
An ORM report with lazy loading: swap.pool.name looks like reading a field, but it is a query. Switch on eager loading, or write the join. Spot it by counting queries per request in the logs.

    

    

      
Where you meet the batch

      
Two services that cannot join: collect the keys, send one IN query per page of about 1,000 keys. A GraphQL server does the same with a dataloader: it collects the keys asked for in one tick and sends one batch.
