Where you meet it

      
One MCP tool server for every agent host. A public REST (representational state transfer) or gRPC API that every partner uses the same way. A Kafka topic with a documented schema as the door of a context.

    

    

      
The practical choice

      
Offer one protocol when you have many consumers, or expect them. Document it and version it. When one consumer needs more, add it to the protocol for all, or say no. Never build a private door.
