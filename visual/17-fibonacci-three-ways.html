Fibonacci three ways

Compute fib(6), which is 8. Same answer, three programs. The first asks the same question again and again. The second remembers. The third never asks twice at all. Watch the call counter.

Where you meet memoization

      
Python functools.lru_cache. A price lookup by token and day in a backfill, where the same pair repeats thousands of times. Edit distance and shortest paths, which are tables of sub-answers. Give a long-running cache a size limit.

    

    

      
Where you meet the loop

      
When the sub-answers form a simple chain, keep only the last few in variables. That is dynamic programming bottom-up: O(n) time and O(1) memory, and no stack to overflow.
