BFS versus DFS

A victim's money left in transfers. An investigator wants the fewest hops from the victim to the exchange. Breadth-first search (BFS) explores hop by hop with a queue. Depth-first search (DFS) dives down one path with a stack. Same graph, two orders.

Where you meet BFS

      
Fund tracing from a victim: one hop, two hops, three hops out, with a hop limit. In a graph database it is a variable-length pattern with a hop bound and a per-node limit, which the engine runs as a bounded BFS. The visited set is a hash set, so cycles end the walk.

    

    

      
Where you meet DFS

      
Cycle detection, connected components, and topological order of migrations or build steps. Backtracking search is DFS with undo. On deep graphs, write it with an explicit stack, not recursion, so the call stack cannot overflow.
