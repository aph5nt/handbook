Where you meet offset

      
Admin screens and search results with "jump to page 7". The list is small, people rarely go past page 10, and a row shown twice does no harm. OFFSET is simple and fine there.

    

    

      
Where you meet keyset

      
Feeds, event logs, swaps of a pool in a warehouse, the GitHub and Stripe list APIs. The cursor encodes the last sort key, such as block height plus log index, so the key is unique. Every page costs the same and never repeats a row.
