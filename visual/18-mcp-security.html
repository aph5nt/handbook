Where you meet it

      
An agent harness runs every test in a throwaway container with an empty HOME. A test once wrote a wallet into the real config folder and the user's own CLI stopped working. The sandbox rule came out of that. A company mirrors the public MCP Registry into a private, allow-listed one: listing is not vetting.

    

    

      
The practical choice

      
Trust annotations only from servers you trust. Always ask before writes. Pin each description's hash at install and alert on change. Run each server with the least file, network and credential access it needs.
