Agent executor: the loop code and its guards

The agent executor is the plain code around the model: send the messages, run the tool the model asks for, paste the result back, repeat. The guards live here: a step cap, a result size cap, a time limit per tool, error handling. Watch one run. Then switch tabs to see the loop with no guards.

Where you meet it

      
LangChain's AgentExecutor, LangGraph's prebuilt ReAct agent, the Claude Agent SDK, and the loop inside Claude Code. Every one is the same small loop. What differs is the guards.

    

    

      
The practical choice

      
Put every guard in the executor, not in the prompt: a step cap, a result size cap, a time limit per tool, a total budget, and a repeat-call check. Return tool errors to the model as results so it can recover. Stop with an honest partial answer when a cap hits.
