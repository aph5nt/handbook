Where you meet it

      
Price vendors: one adapter per vendor turns vendor rows into DayPrice(token, day, usd), so a vendor rename touches one adapter. The Ethereum JSON-RPC (remote procedure call) is stable and standard, so the indexer conforms and saves the translator. One MCP (Model Context Protocol) tool server serves every agent host.

    

    

      
The practical choice

      
Draw the map before a big change, not after an outage. On every arrow, write who is upstream and the pattern. Put a translator in front of anything foreign and messy. Conform only to what is stable. Leave a link out when it gives nothing.
