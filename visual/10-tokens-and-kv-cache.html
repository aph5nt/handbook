Where you meet it

      
Every agent call in a Claude Code harness starts with the same system prompt, tool list and loaded skills. That prefix is the prefill work, and prompt caching removes most of it. Self-hosted serving with vLLM or a similar server keeps the GPU busy with continuous batching: many users share each decode step.

    

    

      
The practical choice

      
Put stable text first and the date, the user and the task last, so the prefix stays the same byte for byte. Trim tool output: a table of addresses is token-heavy. When you size GPU memory, count the weights plus the KV cache at the longest context and the most users at once.
