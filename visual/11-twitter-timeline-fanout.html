Where you meet it

      
Any feed: a social timeline, a notification inbox, an activity stream. Reads are far more common than writes, roughly a hundred to one at Twitter, so you usually pay at write time. Twitter stores each tweet once in Manhattan, its key-value store, and pushes only the 64-bit Snowflake id into caches.

    

    

      
The same shape in a graph

      
A transfer graph projection is fan-out on write: each transfer updates the summary links of both addresses, so a trace reads one neighbourhood. An exchange hot wallet is the celebrity: its links are capped and expanded only when a question needs them.
