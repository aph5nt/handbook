Where you meet it: payments

      
Stripe and most payment APIs take an Idempotency-Key header on every POST that moves money. The key sits in the same database as the payment, written in the same transaction. Keys expire after about a day.

    

    

      
Where you meet it: events and agents

      
A webhook receiver uses the event id as its key, so a second delivery is dropped. An agent that loops or retries a paid tool call needs a key even more than a person does, because it retries without asking anyone.
