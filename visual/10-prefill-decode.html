Where you meet it

      
Every LLM (large language model) call. Time to first token comes from queueing plus prefill. Tokens per second come from decode. Self-hosted servers such as vLLM show both, and keep each request's KV cache in GPU (graphics processing unit) memory.

    

    

      
The practical choice

      
Keep prompts lean, because prefill time and KV cache both grow with prompt length. Size GPU memory for weights plus KV cache at peak users, never weights alone. Cap context length and live requests so one long prompt cannot starve the batch.
