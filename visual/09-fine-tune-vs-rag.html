Where you meet it

      
Chain Insights keeps exchange names in a registry file the proxy reads at run time, never in model weights. Report layouts live in prompts and skills. Fine-tuning fits a small classifier run at very high volume once prompting has proven the task.

    

    

      
The practical choice

      
Start with prompting. Add retrieval or a lookup tool for facts, especially facts that change. Fine-tune last, for behaviour and format at scale, when you have labelled examples and an eval. Never fine-tune to teach facts you need to cite or update.
