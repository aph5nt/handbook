Where you meet it

      
Every LLM (large language model) API call takes temperature and top-p. An address classifier runs at temperature 0 with a schema for the output. A naming or copy tool runs near 0.8 with top-p to cut nonsense. An eval harness runs every case several times, because each run is a draw.

    

    

      
The practical choice

      
Tune one knob, not both at once. Extraction and classification: temperature 0, plus structured output so the label must be one of the allowed words. Creative text: a higher temperature, with top-p near 0.9. Never trust one run to prove the setting works.
