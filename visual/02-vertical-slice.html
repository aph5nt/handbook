Vertical slice architecture

A local MCP (Model Context Protocol) proxy exposes tools: graph_query, wallet_balance, subscription_topup. Cut by layer, a new tool touches three folders. Cut by slice, it touches one. Press Next.

Where you meet it: tool servers and handlers

      
An MCP proxy or an HTTP API with many independent endpoints suits slices: one folder per tool or request. In .NET, Jimmy Bogard's MediatR style gives one handler per request.

    

    

      
Where you meet it: next to a domain core

      
Slices sit well on top of a shared domain core. The core holds rules many slices need. Each slice holds its own request, response and query.
