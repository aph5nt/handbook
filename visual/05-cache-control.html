Where you meet it

      
Every HTTP response from a web server, an API gateway or object storage such as S3. Frameworks often set defaults you never read. A content delivery network (CDN) follows these headers unless you override them in its rules.

    

    

      
The practical choice

      
Never changes: long max-age, immutable, hashed URL. Changes sometimes: short max-age, s-maxage for the edge, an ETag. Per user: private. Sensitive or live: no-store. Check headers in a test, not by eye.
