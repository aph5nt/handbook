Where you meet it

      
Hot keys with a costly source: prices, exchange lists, dashboard totals. Caffeine's refreshAfterWrite in Java. The XFetch algorithm for the probabilistic form. HTTP stale-while-revalidate does the same after expiry instead of before.

    

    

      
The practical choice

      
Refresh a key in the background when a read finds it near expiry, with one refresh per key at a time. Never refresh on a timer for keys nobody reads.
