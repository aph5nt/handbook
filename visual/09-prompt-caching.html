Where you meet it

      
Claude Code and other agent harnesses resend a long system prompt, tool list and skills on every call. Anthropic prompt caching with cache breakpoints, and automatic prefix caching at OpenAI and in vLLM. Chat products with a long fixed system prompt.

    

    

      
The practical choice

      
Order the request from most stable to least stable: system prompt, tools, skills, then history, then the new turn. Put the breakpoint after the stable part. Keep tool order fixed and skills frozen for a session. Watch the cache-read token count in the usage report.
