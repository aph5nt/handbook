Golden set and ablation: prove the skill does its job

A model once shortened an address in an answer. That failure became a case in a golden set, kept in git. The skill that carries the rule is run three times with it and three times without it. Watch the delta prove the skill works. Then switch tabs to see a skill written to pass its own cases.

Where you meet it

      
Skill evals in a Claude Code harness: `claude plugin eval . --runs 3 --ablation with-without`. Regression suites for prompts and RAG pipelines. Any change to a prompt, a model or a retrieval step gets the same with-and-without comparison.

    

    

      
The practical choice

      
Turn every real wrong answer into a case, kept in git with its reason. Run several times and report a pass rate. Compare with and without the change, so you measure its effect, not the model's mood. Keep a held-out set you never look at while writing, and date your reference answers.
