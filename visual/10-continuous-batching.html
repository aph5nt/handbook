Where you meet it

      
vLLM, TGI (Text Generation Inference) and similar servers batch continuously by default. Paged KV cache stores each request's cache in small pages, so requests of any length fit in the gaps. It is what makes one self-hosted GPU (graphics processing unit) serve many users.

    

    

      
The practical choice

      
Cap live requests and context length so the KV cache fits. Load-test at the target number of live requests. Watch time to first token at p95 (the time 95% of requests stay under), not only total tokens per second.
