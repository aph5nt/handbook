Where you meet passkeys

      
Admin consoles, cloud accounts and the Git host: passkeys or hardware security keys. Customer sign-in: offer passkeys first, with a code app as a fallback.

    

    

      
Where you meet codes

      
Apps that cannot yet use passkeys. Use an authenticator app, never SMS, and number matching on push prompts.
