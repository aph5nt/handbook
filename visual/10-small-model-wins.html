Where you meet it

      
Skill routing and intent classification in an agent harness. High-volume address labelling, where a distilled student matches the teacher. On-premises or private data, where only a small model fits the hardware.

    

    

      
The practical choice

      
Run the same golden set on both models before choosing. Close the gap with few-shot examples, a schema, a LoRA adapter or distillation. Keep an escalation path to the big model, and compare total cost including retries.
