Where you meet it: internal and public APIs

      
Internal APIs often carry no version at all, only additive changes. A public API with paying clients pins a version date per account, as Stripe does: the friendliest choice, and the most work.

    

    

      
Where you meet it: an agent tool server

      
Hosts cache tool lists. Add a new tool, and keep the old tool name as an alias with a deprecation note in its description.
