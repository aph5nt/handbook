Join types: which rows survive

Where you meet it

      
Transfers LEFT JOIN prices on day and token: a transfer of a token with no price that day must still appear, with a NULL price, or the report silently loses money. "Addresses that never received a swap" is an anti join written as NOT EXISTS. An ORM's include is a left join; its where on the included table quietly makes it inner.

    

    

      
The failure that matters

      
A filter on the right table placed in WHERE turns a left join into an inner join. LEFT JOIN customers c ... WHERE c.name = 'Ana' drops every order whose customer is NULL, because NULL = 'Ana' is not true. Put the filter in the ON clause. The second trap: NOT IN (subquery) returns nothing at all if the subquery holds one NULL. Write NOT EXISTS.
