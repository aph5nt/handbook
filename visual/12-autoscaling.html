Where you meet it

      
Kubernetes HPA (Horizontal Pod Autoscaler) on a custom metric such as queue depth through KEDA (Kubernetes Event-Driven Autoscaling). Cloud autoscaling groups behind a load balancer. Scale-to-zero batch workers. Never a database primary: adding a copy of state is resharding.

    

    

      
The practical choices

      
Scale on the signal that tracks the work: queue depth or requests in flight for an I/O-bound service, CPU only for CPU-bound work. Set a min that survives the start-up lag of a sudden spike, a max that protects the database behind, and a cool-down longer than the warm-up.
