Where you meet Merkle trees

      
Bitcoin and Ethereum block headers, and light clients that check one transaction. Git: every commit names a tree of hashes. Cassandra and DynamoDB-style repair compare Merkle trees of key ranges and copy only the ranges that differ.

    

    

      
The traps

      
An odd number of leaves: Bitcoin copies the last one, which let two different transaction lists share a root (CVE-2012-2459). A node hash passed off as a leaf: prefix leaves and inner nodes differently before hashing.
