Where you meet it

      
Grafana with Prometheus for metrics, Loki for logs and Tempo for traces, all linked by trace id. An MCP proxy that returns the trace id to the agent, so a user report becomes a trace in one step. A Go indexer with a histogram per stage and a span around each warehouse insert.

    

    

      
The practical choices

      
Write the trace id into every log line and every span. Turn on exemplars so a histogram sample points at a real trace. Sample traces, but always keep the slow and the failed ones (tail sampling). Use metrics for alerts, traces to locate, logs to explain.
