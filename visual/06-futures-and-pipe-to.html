Where you meet it

      
Any I/O (input and output) from inside an actor: a database, an HTTP call, a file. Akka PipeTo, Akka Typed pipeToSelf, Erlang's reply message after an async request. In the IoT backend, every config load and every write to a device was piped back.

    

    

      
The choice you make

      
Never await inside a handler, and never touch state or Sender in a callback. Pipe the result, and the failure, back as a message. If you need the original sender later, put it inside the piped message.
