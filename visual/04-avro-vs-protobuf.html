Avro versus Protobuf

The swap decoder writes a swap event. Another team reads it with an older or newer schema. Avro matches the fields by name. Protobuf matches them by number. Press Next to see which changes each one survives, and the one change that silently corrupts data.

Where you meet Avro

      
Kafka with Confluent Schema Registry, Hadoop and data lakes. The bytes carry no field names, so the reader always needs the writer's schema. The registry id in each message supplies it.

    

    

      
Where you meet Protobuf

      
gRPC, Buf, and service contracts such as a local MCP (Model Context Protocol) proxy and its tool server. Field numbers are on the wire, so a reader can parse without the writer's schema. Mark removed numbers reserved.
