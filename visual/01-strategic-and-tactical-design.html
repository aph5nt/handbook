Where you meet it

      
A new feature that crosses teams: a one-hour map session before the first pull request. An interview design question: name the contexts and their borders before any class. A rewrite: strategic design picks what to cut out first.

    

    

      
The practical choice

      
Start every cross-team change at the map: contexts, owners, arrows. Only then shape the code inside each box. When a design review argues about a class, check first that the class is in the right context.
