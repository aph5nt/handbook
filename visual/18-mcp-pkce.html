Where you meet it

      
Every MCP client signing in to a remote server, desktop or command line. Any app that cannot keep a client secret: mobile, desktop, single-page web. OAuth 2.1 makes PKCE mandatory for all clients.

    

    

      
The practical choice

      
Make a fresh verifier per sign-in. Send S256 only. Refuse a server that offers only plain.
