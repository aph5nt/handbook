Where you meet it

      
A recursive CTE joins its step with UNION ALL. Reconciling two sources runs A EXCEPT B and B EXCEPT A: the rows are the differences. Combining partitions or chains with the same shape is UNION ALL.

    

    

      
The practical choice

      
Write UNION ALL by default. Write UNION only when you want distinct rows, and then make sure the columns hold a real key such as (tx_hash, log_index), so two true repeats stay different. Columns match by position, not by name.
