Where you meet it

      
Caffeine and Guava LoadingCache in Java, ristretto and groupcache in Go, and most ORM second-level caches. The library owns the loader and usually coalesces loads per key.

    

    

      
The practical choice

      
Use read-through when many places read the same data and should load it the same way. Use cache-aside when each caller loads differently. Either way, never store a failed load for the full TTL.
