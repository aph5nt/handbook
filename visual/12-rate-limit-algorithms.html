Where you meet it

      
Token buckets in most API gateways and in the AWS (Amazon Web Services) API throttles. Leaky buckets in NGINX's limit_req, which queues and drains at a fixed rate. Sliding-window counters in Redis with an atomic script, used by many rate-limit libraries. Fixed windows in simple per-minute quotas.

    

    

      
The practical choices

      
Token bucket when short bursts are fine. Leaky bucket when the thing behind must see a smooth rate. Sliding window when the edge burst matters. A sliding-window log keeps one timestamp per request, so most systems use the cheaper sliding-window counter, which weights the previous window.
