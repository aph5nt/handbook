Where you meet it

      
Memcached clients place keys with consistent hashing. Redis Cluster uses fixed slots that move between nodes, with the same goal: a node change moves few keys. Detect hot keys first: count in the client, or use the hot-key report of Redis.

    

    

      
The practical choice

      
Scale the cluster for many keys. For one hot key, put a small local cache with a short TTL in each service, or store copies under several names with a random suffix on read.
