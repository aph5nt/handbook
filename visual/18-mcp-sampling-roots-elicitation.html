Sampling, roots, elicitation: the server asks back

Usually the host asks and the server answers. Three features turn that around. A query returns 5,000 rows, so the server asks the host's model to summarise them. A filesystem server is told which folder it may touch. A top-up tool asks the user to confirm the amount. Press Next in each tab.

Where you meet it

      
Claude Code passes the open repository as the one root, and a filesystem server refuses paths outside it. A summarising server checks for sampling and pages instead when the host has none. A spending tool confirms the amount through elicitation.

    

    

      
The practical choice

      
Treat all three as optional. Check the client's capabilities before you ask. Never rely on roots for safety: sandbox the server process. Never ask for a secret through a form.
