Where you meet it: stateful pods

      
The warehouse, the graph and the graph sync set memory request equal to limit. A limit change goes to both lanes in one change, with a comment naming why.

    

    

      
Where you meet it: services and autoscaling

      
Latency-sensitive Go or Java services often keep a CPU request and drop the CPU limit. A Horizontal Pod Autoscaler (HPA) scales a query API on CPU, never a single-writer indexer with one checkpoint.
