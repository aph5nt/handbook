Long-running operations: 202 Accepted

An analyst asks for a year of transfers as a file. Building it takes many minutes. Press Next and compare holding the request open with answering 202 Accepted and a job to poll.

The code that runs this step

The lit lines are the ones the current step runs. A short client timeout stands in for the load balancer's idle timeout, and the worker is called step by step so the output never changes. Full program: handbook/code/13-long-running-operations/main.go (go run .).

Where you meet it: exports and cloud APIs

      
Reports, exports and re-indexing a range of blocks. Creating a database or a cluster in a cloud API returns an operation to poll.

    

    

      
Where you meet it: agent tools

      
A tool returns a job id at once, and a second tool checks it, so a call never hits the host's tool timeout.
