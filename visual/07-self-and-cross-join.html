Where you meet it

      
Self joins: two-hop money paths, an employee and their manager in one table, rows that must agree with each other. Cross joins: calendar grids that show zeros, every combination of two settings in a test. Older code compared a row with the previous one by a self join. Today LAG does it.

    

    

      
The practical choice

      
Always write JOIN ... ON, never the comma form FROM a, b. Bound every self join on transfers by time. Run a COUNT(*) before the full query when a join could fan out.
