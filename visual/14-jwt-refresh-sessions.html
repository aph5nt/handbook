Where you meet a JWT

      
A public API called by agents and services: short-lived bearer JWTs, verified with RS256 or ES256, so the verifier holds only a public key and never the signing secret.

    

    

      
Where you meet a session

      
A browser app with a server behind it: an HttpOnly, Secure, SameSite session cookie. Never keep a token in browser local storage, where any script on the page can read it.
