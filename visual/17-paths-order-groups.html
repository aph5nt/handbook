Shortest paths, order and groups

Database migrations must run in order: pricing first, because the EVM migration depends on it, and the graph sync layer after the tables it reads. Three graph tools answer three questions: in what order, by which cheapest path, and in the same group or not.

Where you meet them

      
Ordering migrations, build targets and graph sync layers: topological sort. Connected components of a transfer graph, and clustering wallets that share a funding source: union-find. Route planning and network routing: Dijkstra, and A* when an estimate of the distance left can steer the search.

    

    

      
The choice you make

      
Negative weights: use Bellman-Ford, not Dijkstra. A cycle in a dependency graph: detect it and report it, never pick an order. Union-find: always add path compression and union by rank.
