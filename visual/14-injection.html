Where you meet SQL injection

      
Every database call: parameters, always. A graph query tool sends the address as a parameter, so it can only be an address. Every label shown to a user is escaped, plus a Content Security Policy.

    

    

      
Where you meet prompt injection

      
Any agent that reads the web, an email or a tool result. Treat the text as hostile. Give that agent few tools and no production credential, and keep it apart from the agent that holds rights.
