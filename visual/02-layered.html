Where you meet it: admin tools

      
A small admin tool over Postgres: controller, service, repository. Spring and ASP.NET tutorials use this shape. For a CRUD screen with few rules it is the right choice.

    

    

      
Where you meet it: when it stops fitting

      
When rules grow and tests need a fake database, move the rules into a core and turn the repository into an adapter behind a port. That is the hexagonal step.
