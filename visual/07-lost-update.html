Where you meet it

      
Wallets and quotas: one conditional UPDATE, and zero rows means refused. Stock counts: SET stock = stock - 1 WHERE stock > 0. Counters: SET views = views + 1, never read, add one, write back.

    

    

      
The practical choice

      
Do not trust the default level. Read committed does not stop a lost update. PostgreSQL's repeatable read detects it and aborts the second writer. MySQL's repeatable read does not. Push the arithmetic into the UPDATE and the question goes away.
