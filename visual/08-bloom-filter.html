Where you meet it

      
StarRocks bloom_filter_columns on tx_hash in a table sorted by pool. LSM stores such as RocksDB and Cassandra keep one per file, so a read skips files. Hash joins send a runtime bloom filter of the build keys to the probe-side scan.

    

    

      
The practical choice

      
Use a bloom filter for equality lookups on a column with many values that the sort key does not cover. Size it by keys, about 10 bits per key for about 1 percent false alarms. Never for ranges or for columns with few values.
