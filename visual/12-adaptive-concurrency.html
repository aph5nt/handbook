Adaptive concurrency limits: learn the limit from latency

An MCP (Model Context Protocol) proxy must decide how many queries to send to a graph lane at once. The right number changes with the graph's load. Watch the limit climb while latency stays flat and halve when latency rises, then watch a fixed limit fail on a busy day. Press Next.

Where you meet it

      
Netflix's concurrency-limits library replaced fixed thresholds after Hystrix was retired in 2018. Envoy's adaptive concurrency filter does the same in a proxy. TCP (Transmission Control Protocol) congestion control is the original: AIMD on the congestion window.

    

    

      
The practical choices

      
Put the limit at the client side of each dependency. Measure latency per request and keep a running minimum as the baseline. Grow the limit slowly while latency holds, cut it fast when latency rises. Refuse requests above the limit at once, with a clear error. Keep a floor and a ceiling.
