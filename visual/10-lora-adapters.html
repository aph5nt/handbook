Where you meet it

      
A fixed report format on a small, fast model. Several tasks on one GPU (graphics processing unit): one base, many adapters, swapped per request, as vLLM and similar servers allow. QLoRA trains an adapter on a 4-bit quantized base so it fits on smaller cards.

    

    

      
The practical choice

      
Use an adapter for shape and style only. Pin it to its exact base model version. Keep the eval set from before training and run it after. Facts stay in retrieval, where they can change every day.
