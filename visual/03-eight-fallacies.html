Where you meet it

      
A Go indexer calling a chain node's RPC (Remote Procedure Call) endpoint: batch the calls instead of one per block, and set a timeout on each. A review before splitting a service: count the calls one page makes across the network.

    

    

      
The choice you make

      
Treat every timeout as 'I do not know'. Make retries safe with an idempotency key. Batch chatty calls. Encrypt traffic even inside the private network, such as every API between data centres.
