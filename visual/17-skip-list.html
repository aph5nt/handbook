Where you meet skip lists

      
Redis sorted sets (ZSET): a skip list for order plus a hash map for lookup by member. The memtable of LevelDB and RocksDB. Java ConcurrentSkipListMap, an ordered map that many threads update without one big lock.

    

    

      
The choice you make

      
A skip list against a balanced tree: the same O(log n), much simpler code, and easy to make lock-free. The price is randomness: use a good random source so nobody can game the levels.
