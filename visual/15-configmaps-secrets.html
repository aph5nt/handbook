Where you meet it: per lane

      
Settings for each lane live in a ConfigMap rendered from the lane values file. A checksum annotation rolls the pods when it changes.

    

    

      
Where you meet it: credentials

      
Database and API credentials live in Secrets synced from an external store (Vault, a cloud secret manager) or sealed in git, readable only by the service account that needs them.
