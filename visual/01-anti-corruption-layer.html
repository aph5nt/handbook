Where you meet it

      
Price vendors and any third-party API with its own model. A legacy system you are cutting a context out of. A tool result from an LLM (large language model) turned into a typed object before the agent's code uses it.

    

    

      
The practical choice

      
Write one adapter per foreign source, and nothing else knows the source. Test each adapter with real rows from the source. Translate names, units and time zones in one place. Keep the adapter thin: translation only, no business rules.
