Where you meet it

      
Cassandra, DynamoDB and Redis Cluster place keys on a ring or in hash slots, so adding a node moves a slice. A warehouse partitioned by day of block time is range sharding instead: old days are cold, today is hot, and for append-only data that is fine.

    

    

      
The practical choices

      
Shard on the key most queries filter by, with an even spread. Check the top values for a hot key before you choose. Use virtual nodes so arcs stay even. Fix a hot key by splitting it, caching it, or coalescing identical reads, as Discord did for big channels.
