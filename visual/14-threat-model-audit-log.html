Where you meet a threat model

      
Agent tool servers: host, proxy, lanes, with the boundaries marked. Run STRIDE at each boundary on design, and again for every new integration or credential.

    

    

      
Where you meet an audit log

      
Every privileged call. Production changes as merged pull requests, so git history is the log. Under GDPR (General Data Protection Regulation), a label naming a person turns an address into PII (Personally Identifiable Information).
