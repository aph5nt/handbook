Where you meet full state in the event

      
When readers must keep working while the source is down. A graph that is a projection of a warehouse reads full rows and never calls the indexer. Use a bare notification only for rare, heavy objects.

    

    

      
Where you meet the claim check

      
Block receipts, images, exports: anything too big for a message. The blob goes to object storage, such as S3, and the message carries its path. Put a correlation id in every message header and pass it on unchanged, so a trace follows the flow.
