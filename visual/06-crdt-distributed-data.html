Where you meet it

      
Akka Distributed Data: online counts, feature flags, a set of banned devices, replicated by gossip. Riak, Redis Enterprise active-active and collaborative editors use CRDTs too. Writes and reads can ask for the local node, a majority, or all.

    

    

      
The choice you make

      
CRDTs for values that may disagree for a moment and must never conflict: counters, sets, flags. Rules that must never break, such as "one booking per technician", go to a single owner: a sharded actor or a database row.
