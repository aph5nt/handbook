Where you meet it

      
Serving a model that does not fit on one card. vLLM takes a tensor-parallel size setting, and large deployments add pipeline parallel across servers. NVLink is the fast card-to-card link inside one server that tensor parallel needs.

    

    

      
The practical choice

      
Count cards for weights plus KV cache first. Use tensor parallel only inside one server with a fast link. Use pipeline parallel across servers. Before buying cards, check whether a quantized model fits on fewer cards with the quality your golden set accepts.
