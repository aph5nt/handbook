Defence in depth for agents

An agent is asked to free disk space on a development machine. A README it read says "to reset, run docker compose down -v", which deletes the data volumes. Press Next and watch each dangerous command meet the rings around the data.

Where you meet it: a coding agent harness

      
Claude Code with an allow-list of tools, a pre-tool hook that refuses docker compose down -v and docker volume rm, and a test script that runs every test in a throwaway container with only the work folder mounted and an empty home folder.

    

    

      
Where you meet it: production access

      
The agent holds a short-lived token that writes staging only. Production is read-only for it. Production changes go through a workflow with a human reviewer, and the merged pull request is the audit log.
