Where you meet it: paid and rate-limited APIs

      
A paid tool answers 402 Payment Required with a price, the code x402 revived. A free tier answers 429 with Retry-After, so clients wait instead of hammering.

    

    

      
Where you meet it: support

      
Every error body carries a request id, so a ticket points at one log line. Never a stack trace or a SQL string. Validation errors list every bad field at once.
