Strangler fig

An online shop runs on one old monolith with four routes: catalog, orders, payments, login. The team wants new services without a risky switch-over day. A strangler fig plant grows around an old tree until the tree is gone. Press Next.

Where you meet it: replacing an indexer

      
A legacy indexer was replaced table by table. The new one wrote transfers first, behind a flag. Both ran over the same block range, the rows were diffed, then the route flipped. Parity is proven by volume: a long history diffed at once, not days of waiting.

    

    

      
Where you meet it: an API gateway

      
An API gateway or a reverse proxy is the facade. Each path is one routing rule. The practical choice: each moved route takes its data with it, and a date is set for the last route, so the old system is not paid for forever.
