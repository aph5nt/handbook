Mixture of experts: each token uses a few experts, memory holds them all

Where you meet it

      
Model specs list both total and active parameters for mixture-of-experts models. Self-hosting one means GPU (graphics processing unit) memory for every expert plus KV cache. It explains why a model with a huge parameter count can still be fast per token.

    

    

      
The practical choice

      
Size memory by the total parameters. Size compute and speed by the active parameters. Watch per-expert load on your own traffic, because uneven routing turns one expert into the bottleneck.
