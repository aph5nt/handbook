Coupling and cohesion

The dex module asks the pricing module for a day price. How much must one know about the other to change? That is coupling. Do the things inside each module belong together? That is cohesion. Press Next.

Where you meet it: reviews

      
Import graphs show code coupling only. Ask also: which tables does it read, what must run first, what must ship with it, and what does each field mean? Connascence is the formal name for these kinds.

    

    

      
Where you meet it: service splits

      
A split along a seam with high data or deploy coupling creates a distributed monolith. Measure coupling before cutting, and cut where it is lowest.
