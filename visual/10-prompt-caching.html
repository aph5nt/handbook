Prompt caching: pay for the stable prefix once

Every call of an agent session starts with the same system prompt, tool list and loaded skills: about 20,000 tokens. Press Next and watch the second call read that prefix from cache. Then open the second tab and watch one changed character at the top make every call miss.

Where you meet it

      
A Claude Code agent harness: the system prompt, the tools and the loaded skills are the same on every call of a session, so they form a cached prefix. Hosted APIs price cached input at a fraction of normal input and give a faster first token.

    

    

      
The practical choice

      
Stable text first, in the same order every time. The date, the user's name and the task go at the end. Never add a timestamp or a random ID to the top of the system prompt. Check the cache hit rate in the traces after every prompt change.
