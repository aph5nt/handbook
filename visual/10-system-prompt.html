Where you meet it

      
A Claude Code agent harness: the system prompt plus loaded skills carry every rule that must survive compaction. A product with many customers shares one cached system prompt and puts customer data in later turns.

    

    

      
The practical choice

      
Keep it short, fixed and trusted: role, a few clear rules, one or two examples. Put the date, the user's name and pasted documents later in the conversation. Any rule that must never break is also enforced in code.
