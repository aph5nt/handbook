Where you meet it: a multi-tenant API

      
Every query filters by the tenant in the token, never by a tenant id from the request. One identity per service, each with its own narrow role.

    

    

      
Where you meet it: a code review

      
For every new endpoint, ask who may call it and on whose data. A test that calls it with another tenant's id must get 403 or 404.
