Where you meet it: special hardware

      
GPU and very large memory nodes carry a taint. Only workloads that need them carry the toleration and the node affinity.

    

    

      
Where you meet it: replicas

      
Database replicas use pod anti-affinity per node, or topology spread constraints across zones, so one node or zone loss never takes them all.
