Where you meet routers

      
Akka round-robin, smallest-mailbox and consistent-hashing pools. Kafka does the same with partitions: messages with one key go to one partition, so one consumer sees them in order. A load balancer in front of stateless web servers is a round-robin router.

    

    

      
The choice you make

      
Stateless work, such as parsing or enrichment: round robin, or smallest mailbox when work sizes differ. Work with state or order per key: consistent hashing by the entity key. Across several machines, use cluster sharding, which also moves state when nodes change.
