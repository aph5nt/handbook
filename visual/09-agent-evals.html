Agent evals: ten runs, not one

One agent task, run ten times. Each run passes or fails the same checks. The pass rate is the result, not any single run. Watch a skill earn its place against runs without it (ablation). Then switch tabs to see a skill change judged on one lucky run ship a drop from 8 of 10 to 5 of 10.

Where you meet it

      
`claude plugin eval . --runs 3 --ablation with-without` in a Claude Code harness: each case runs several times with the skill and without it, and the report gives both pass rates and the delta. LangSmith and promptfoo run the same idea as experiments over a dataset.

    

    

      
The practical choice

      
Run every case several times, with and without the change. Compare pass rates, not single runs. Block a merge when the rate drops, even when the run you looked at was green. Raise the run count when two rates are close.
