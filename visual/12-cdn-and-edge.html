Where you meet it

      
Cloudflare, Fastly, Akamai or CloudFront in front of a website, documentation, images and downloads. A short TTL (time to live) on public, slow-changing API answers. Edge functions for redirects, geo rules and cheap auth checks.

    

    

      
The practical choices

      
Long TTLs with versioned file names for static files, so a new release is a new name and needs no purge. Purge by path or tag, never everything. Serve the stale copy while one request refreshes it. Mark personal responses Cache-Control: private and keep cookies out of the cache key unless the response really varies by them.
