Where you meet it: cloud resources

      
Networks, buckets, DNS, managed databases and access roles are Terraform or Pulumi files. A scheduled plan that should print no changes catches hand edits.

    

    

      
Where you meet it: where it stops

      
Terraform builds the cluster. Helm and a GitOps controller fill it. One tool per layer keeps two tools from fighting over the same object.
