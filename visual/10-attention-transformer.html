Where you meet it

      
Every modern LLM (large language model) is a transformer. Long prompts slow the first token because prefill does all the comparisons. The KV cache in a serving stack such as vLLM stores the keys and values so decode does not redo them.

    

    

      
The practical choice

      
Keep prompts lean: trimmed tool output costs less attention work, not only fewer tokens. Use a model and server built for long context only when the task truly needs it. Read layers, heads and context length on a model card as numbers from this design.
