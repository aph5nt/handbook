Feature flags: deploy is not release

An agent proxy gets a new way to plan graph walks. The code ships to every copy, switched off. Each square is one tenth of the agents. Watch the flag release it step by step and switch it off in seconds, then watch old flags rot. Press Next.

Where you meet it

      
A percentage rollout of a new query planner, keyed by API key so each agent sees one path. A kill switch for an expensive feature, such as deep graph walks, during an incident. LaunchDarkly or Unleash as a service, or a small config file the code reads at run time.

    

    

      
The practical choices

      
Key the rollout on a stable id, so a user does not flip between paths. Compare the flagged group's error rate with the rest. Give every flag an owner and an expiry date. Delete the flag and the old path after full rollout. Keep only a few long-lived operational switches, and test them.
