Where you meet it: fast local data

      
Warehouse and graph data use a local NVMe class with WaitForFirstConsumer and Retain. The pod is tied to its node, so the application keeps copies on other nodes.

    

    

      
Where you meet it: replicated and cloud

      
A replicated class (Longhorn, Ceph) holds small data that must survive a node loss. Cloud disk classes are tied to one availability zone, so their pods are too.
