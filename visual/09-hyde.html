HyDE: search with a fake answer

An engineer types three words: "lane B stuck?" That is too short to embed well. HyDE (hypothetical document embeddings) asks the model to write a fake answer first, and searches with the fake answer's vector. Watch the search improve. Then switch tabs to see the fake answer invent a script name.

Where you meet it

      
Search over runbooks or docs where users type very short questions. LlamaIndex and LangChain ship HyDE query transforms. It pairs well with keyword search and a re-ranker.

    

    

      
The practical choice

      
Use HyDE for short, vague questions on the vector side only. Keep keyword search on the user's own words. Throw the fake answer away after the search, and never show it. Skip HyDE for long, specific questions: they embed well already, and HyDE adds one model call.
