Embeddings: meaning as a place on a map

An embedding model turns each chunk into a vector, a list of numbers. Chunks that mean similar things land close together. A question is embedded the same way, and search returns its nearest neighbours. Watch 'where do swaps live' find the swap table with no shared words. Then switch tabs to see an exact name get lost.

Where you meet it

      
Vector search in QMD, pgvector in Postgres, Qdrant, or a vector index inside a search engine. Semantic search over runbooks, support tickets and code. Clustering similar incidents.

    

    

      
The practical choice

      
Use the same embedding model for chunks and questions, and record its name with the index. Pair vector search with keyword search for names and identifiers. Plan a full re-embed when you change the model, because old and new vectors cannot be compared.
