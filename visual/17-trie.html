Where you meet tries

      
Autocomplete and name search. Network routers find the longest matching prefix of an IP address with a radix trie. Ethereum keeps account state in a Merkle Patricia trie keyed by address. Go HTTP routers such as httprouter match paths with a radix tree.

    

    

      
The choice you make

      
A plain trie wastes memory: one node per letter, each with room for every possible child. Use a radix trie that merges single-child chains, or a sorted array where a prefix is a range found by binary search.
