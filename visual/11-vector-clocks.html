Where you meet it

      
Riak keeps siblings and uses dotted version vectors, a refined vector clock. CRDTs (conflict-free replicated data types) build the merge into the data type. Git asks the same question: two commits that do not include each other must be merged.

    

    

      
The choice you make

      
Use last-write-wins only when losing one of two concurrent writes is fine, such as a "last seen" time. Keep both versions when each write matters, like a cart, and record deletes so a merge cannot bring items back.
