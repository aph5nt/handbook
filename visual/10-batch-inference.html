Where you meet it

      
The Anthropic Message Batches API and the OpenAI Batch API take a file of requests and return results within a stated window at a lower price per token. Typical jobs: nightly labelling, re-embedding a whole store, running a big eval suite, backfills after a prompt change.

    

    

      
The practical choice

      
Batch for offline work only. Give every request its own ID and match results by that ID, never by position. Make each request safe to retry, and resend only the failed ones. Chat, agent loops and anything a person waits on stay live.
