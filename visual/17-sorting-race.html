Sorting race

Twelve transfers must be sorted by amount. Four algorithms start on the same shuffled list, one lane each. Every Next gives each lane the same number of extra operations, where one operation is one comparison or one move. Count who finishes first, then try the second tab.

Where you meet these sorts

      
Python and Java objects use Timsort: merge sort that finds runs already sorted, plus insertion sort on short runs. C++ std::sort and .NET use introsort: quicksort that falls back to heap sort when it recurses too deep. Go uses pattern-defeating quicksort since 1.19.

    

    

      
Where stability matters

      
Sort a day of transfers by block, then by address. A stable sort keeps each address's transfers in block order. Go's sort.Slice is not stable, so use sort.SliceStable. A database ORDER BY that spills to disk is an external merge sort.
