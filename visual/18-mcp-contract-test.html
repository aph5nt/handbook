Where you meet it

      
By hand: the MCP Inspector, a browser tool that connects, lists and calls. In CI: the contract test, on every push. For a release: a clean install of the published package and one tiny real call.

    

    

      
The practical choice

      
Keep unit tests for the logic. Add one contract test that is a host: real binary, real handshake, real tools/list. Snapshot the list so a description change is a reviewed diff.
