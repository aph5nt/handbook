Where you meet it

      
Every browser and every content delivery network (CDN) such as Cloudflare, Fastly or CloudFront. Hashed static files like app.3f9a.js get a max-age of a year, because a deploy changes the name. A CDN can purge by tag, but hashed URLs mean you never need to.

    

    

      
The practical choice

      
Pick the header by how the answer changes. Never changes: long max-age and a hashed URL. Changes sometimes: short max-age and an ETag. Per user: private. Sensitive or changing every moment: no-store.
