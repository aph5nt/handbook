Prefix sums

A dashboard asks how much moved between two blocks, many times a minute, for many ranges. Build running totals once. Then every range is one subtraction. The last step shows what one update costs.

Where you meet prefix sums

      
SQL SUM(amount) OVER (ORDER BY block) is a running total. A balance at a block is the prefix sum of transfers in and out. Image tools use the two-dimensional version, a summed-area table.

    

    

      
When the data changes

      
One early update moves every later total: O(n). With frequent updates use a Fenwick tree (binary indexed tree), O(log n) for update and for range sum. Sum token amounts in a type wider than 64 bits.
