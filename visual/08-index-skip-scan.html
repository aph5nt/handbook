Where you meet it

      
A leading column with few values: chain, region, a handful of tenants, a status. MySQL 8 reports "Using index for skip scan". PostgreSQL 18 added skip scan to B-trees. Oracle has had it for years.

    

    

      
The practical choice

      
Let skip scan save you a second index for a rare report. For a hot query, build an index whose leading column the query filters on.
