Where you meet it: stateless APIs

      
Argo Rollouts or Flagger run the steps and the comparison automatically, using per-version metrics from Prometheus or a mesh. A feature flag can ship the code dark first.

    

    

      
Where you meet it: data platforms

      
When a release rebuilds tables for hours, a canary does not fit. Two full lanes and a pointer do the same job: the old lane serves until the new one is proven.
