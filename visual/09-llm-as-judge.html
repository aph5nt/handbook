Where you meet it

      
The soft half of a skill eval: is the answer complete, is it plain. Comparing two prompt wordings pairwise. LangSmith and OpenAI evals both run judges. Hard rules such as address length stay in code.

    

    

      
The practical choice

      
Run hard checks in code first, and give the judge only what code cannot check. Write the rubric as yes-or-no questions with a reference answer. Use a different model from the one that wrote the answer. Swap the order in pairwise judging. Check the judge against human labels on a sample.
