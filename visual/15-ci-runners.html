Where you meet it: private, heavy tests

      
Integration tests with real databases and fixtures run on self-hosted runners on a build host, with warm caches. The required check on each pull request is the merge gate.

    

    

      
Where you meet it: public or untrusted

      
Open source repositories and pull requests from forks run on hosted runners. Image builds run on demand only, so the runners spend their time on tests.
