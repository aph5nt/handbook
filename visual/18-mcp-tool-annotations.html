Where you meet it

      
Claude Code and Claude Desktop read readOnlyHint and destructiveHint to decide when to ask. A graph proxy marks every query read-only. A spending tool marks itself destructive and not idempotent.

    

    

      
The practical choice

      
Set honest hints on your own tools. As a host, trust hints only from allow-listed servers. Defaults are cautious: not read-only, destructive, not idempotent, open world.
