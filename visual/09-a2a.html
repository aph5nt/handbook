A2A: one agent hands a task to another

The Chain Insights investigation agent needs a sanctions screening that a partner's compliance agent does. With A2A (the Agent2Agent protocol), it reads the partner's Agent Card, sends a task, and follows the task's state until a result comes back. Watch the task move through its states. Where you meet it

      
Agent2Agent, an open protocol started by Google in 2025 and now run under the Linux Foundation. Partner agents in compliance, payments or travel that you cannot see inside. MCP connects an agent to tools; A2A connects an agent to another agent.

    

    

      
The practical choice

      
Talk only to agents on an allow-list, over authenticated connections. Check that the Agent Card comes from the partner's own domain. Send the minimum data the task needs. Treat the returned result as data from a third party, and cite it as theirs.
