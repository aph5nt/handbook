GraphQL schema and query cost

The schema says an address has transfers, and a transfer has a sender, which is an address again. A caller writes a query that nests ten levels deep. Press Next and compare a server that prices queries with one that runs whatever it gets.

Where you meet it: GitHub's public API

      
Every GraphQL query has a computed cost, charged against a rate limit in points rather than calls.

    

    

      
Where you meet it: schema changes

      
The schema follows the same additive rules as REST: add fields, mark old ones with @deprecated, never remove in place.
