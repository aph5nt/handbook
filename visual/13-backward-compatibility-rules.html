Backward compatibility rules

A transfers API changes over a year. A strict client crashes on anything unexpected. A tolerant client ignores what it does not know. Press Next and watch each change reach both.

Where you meet it: protobuf and gRPC

      
The rules are built in: never reuse a field number, new fields are optional, and unknown fields are kept and ignored.

    

    

      
Where you meet it: JSON APIs and agent tools

      
The OpenAPI diff linter flags removed fields, new required inputs and type changes. For agent tools, a new optional input is safe, but a renamed tool breaks every host that cached the list.
