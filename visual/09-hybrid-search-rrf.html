Hybrid search and reciprocal rank fusion

An engineer asks: "How do I reset core_dex_swaps on lane B?" A keyword search (BM25) and a vector search each return a ranked list. Their scores are on different scales. Reciprocal rank fusion (RRF) merges the lists by rank position instead. Watch the fused list form. Then switch tabs to see a merge by raw score bury a good hit.

Where you meet it

      
QMD over a harness knowledge base: BM25 finds core_dex_swaps exactly, vectors find 'where do swaps live'. Elasticsearch and OpenSearch hybrid queries. Postgres with a full-text index next to pgvector.

    

    

      
The practical choice

      
Run both searches, take the top 50 of each, and fuse with RRF using k = 60. RRF needs no tuning and ignores score scales. Send the fused top candidates to a re-ranker. Weight one side only if an eval shows it helps.
