Where you meet it

      
Any database restart before traffic: Postgres has pg_prewarm, a graph database needs a warmer. A service deploy: preload the hottest keys before the instance joins the load balancer.

    

    

      
The practical choice

      
Warm in order of value: the structure first, then the newest values. Keep the warmer running, because the hot set follows the live data. Give memory to the buffer pool before you add an application cache that holds the same pages again.
