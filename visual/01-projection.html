Where you meet it

      
The graph sync: warehouse rows projected into a graph. A search index or a dashboard table fed from Kafka. Any read model in CQRS (Command Query Responsibility Segregation).

    

    

      
The practical choice

      
Write the checkpoint in the same transaction as the read model, when the store allows it. Make every write idempotent, keyed by a stable id. Keep the projector able to start from zero, and rebuild instead of repairing.
