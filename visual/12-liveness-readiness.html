Where you meet it

      
Kubernetes startupProbe, readinessProbe and livenessProbe on every long-running pod. A cloud load balancer health check is a readiness check: it decides who gets traffic. A graceful shutdown fails readiness first, so traffic drains before the process stops.

    

    

      
The practical choices

      
Liveness checks only the process: the HTTP handler answers, no deadlock. Readiness may check what the copy needs to serve: warm cache, database reachable, schema present. Give slow starters a startup probe, so they are not killed while loading. Never let one shared dependency fail every liveness check at once.
