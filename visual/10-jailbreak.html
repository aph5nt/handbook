Where you meet it

      
A multi-customer product: the data layer filters every query by the caller's customer, whatever the model asks for. A Claude Code harness: hooks block dangerous commands however they were argued for. Red-team evals: known jailbreak prompts kept in the golden set and run on every change.

    

    

      
The practical choice

      
Treat the model's refusals as a help, not a security boundary. Give tools the user's own permissions, never a master key. Filter inputs and outputs, and keep an audit log. New jailbreaks appear all the time, so the wall must not depend on the model.
