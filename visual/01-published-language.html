Where you meet it

      
A table dictionary for warehouse tables. JSON Schema, Protocol Buffers or Avro schemas for messages between teams. MCP tool descriptions and input schemas: the one text every agent host reads.

    

    

      
The practical choice

      
Write names, units and meaning for every field. Version the format and keep old readers working. Pair it with an open host service: the service is the door, the published language is what goes through it.
