Where you meet XSS

      
Any page that shows user data: labels, comments, names, file names. Admin consoles get the strictest CSP, because XSS there runs with admin rights.

    

    

      
The practical choices

      
A template engine that escapes by default. textContent, never innerHTML. A CSP with nonces. Session cookies marked HttpOnly so a script cannot read them.
