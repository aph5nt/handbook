Where you meet it: shared records

      
Any document or configuration edited by more than one client: a watch list, a dashboard layout, a Kubernetes object (its resourceVersion is the same idea). Agent harnesses where several agents may touch one record.

    

    

      
Where you meet it: HTTP caches

      
A browser or a CDN (Content Delivery Network) sends If-None-Match with the ETag it holds. The server answers 304 Not Modified and saves the body.
