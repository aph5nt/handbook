Where you meet it: indexer and sync

      
An indexer streaming decoded blocks to a sync service uses gRPC server streaming: one connection, typed messages, generated code on both sides.

    

    

      
Where you meet it: the public face

      
Browsers and agents get REST and MCP (Model Context Protocol) tools. A product with many front ends over a graph of linked data gets GraphQL, with DataLoader and cost limits from day one.
