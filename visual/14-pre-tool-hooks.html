Where you meet hooks

      
Coding agents such as Claude Code: refuse known destructive commands and writes outside the work folder. Post-tool hooks run a formatter or log the call.

    

    

      
Policy as code

      
The hook file is reviewed in Git like any other code. Its refusal reasons are written for the model to read.
