Where you meet it: microservices

      
Services owned by different teams, where an end-to-end test environment is slow and flaky. Pact and a broker replace most of it.

    

    

      
Where you meet it: public APIs and agent tools

      
You cannot collect pacts from strangers, so a public API uses the OpenAPI diff instead. An agent tool server records the calls real hosts make and replays them in the build.
