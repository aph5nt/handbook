Where you meet it

      
Cassandra and DynamoDB place data partitions on a ring with virtual nodes. Memcached clients and many proxies pick a cache node with a ring. Discord and others use it to pick which server owns a channel or a user.

    

    

      
The practical choices

      
Use many virtual nodes per real node, often around a hundred, so arcs stay even and a leaving node spreads its keys. Give a bigger machine more virtual nodes. Rendezvous hashing is a simpler rival with the same property. Neither fixes a hot key: split or cache that key.
