Where you meet it

      
An agent API with three caller classes, each with its own bucket size, enforced in the proxy before the query costs anything. An edge rate limiter in front of the origin. Redis with an atomic Lua script as the shared counter for many proxy copies. Envoy and NGINX ship rate limiters.

    

    

      
The practical choices

      
Token bucket when bursts are fine and floods are not. Leaky bucket when the output must be smooth. Sliding window when the edge burst matters. One shared counter, not one per copy. Decide in advance what happens when the counter store is down: fail open keeps the product up, fail closed protects the backend.
