State graph and a human in the loop

A graph query helper writes a statement, runs it and grades the rows. The server refuses it with a reason. A conditional edge sends the state to a rewrite node. After three tries it stops and reports. Before the answer leaves, the run pauses and a human approves. Watch the shared state on the right change after every node.

Where you meet it

      
LangGraph is the standard name for this pattern: nodes, conditional edges, a checkpointer and an interrupt. A production change behind a pull request is the same shape: the merge is the human approval that resumes the flow. When something breaks, you replay from any saved checkpoint with a changed input.

    

    

      
The practical choice

      
Keep the state as typed fields, so an edge can read attempts as a number. Save a checkpoint after every node, so a pause can last a night. Keep tokens and keys out of the state: the checkpoint is written to a database, so treat it like a log anyone may read.
