Where you meet it: design reviews

      
Name the level out loud. A JSON-RPC (Remote Procedure Call) API between two internal services is a fair choice. Call it RPC, not REST, and do not expect caches to help.

    

    

      
Where you meet it: public APIs

      
Level 2 for data. Level 3 only for flows whose next step depends on state, such as pay, refund and cancel.

    

  


  

    
Side by side

    

      
LevelWhat it addsWhat HTTP tools can do

      
0One URL, POST, action in bodyNothing: every call looks unsafe

      
1A URL per resourceName things, still no caching

      
2Real verbs and status codesCaches, safe retries, monitoring by code

      
3Links to next actions (HATEOAS)Clients follow state from the server

      
Interview line"The Richardson model is a ladder: resources, then verbs and codes, then links, and most good APIs stop at level 2 on purpose."
