Where you meet it

      
Graph labels such as Mixer and Exchange are the same words an analyst writes in a report. Event names such as WalletToppedUp are part of the language too. A test name is the cheapest place to enforce the word.

    

    

      
The practical choice

      
Keep a short glossary in the repository, next to the code. When code needs a new word, ask the business first and add it there. In review, refuse a second name for an idea that already has one.
