Where you meet LRU

      
Redis with maxmemory-policy allkeys-lru (it samples a few keys and drops the oldest of those). Database page caches, often as a cheaper "clock" version. Process caches like Caffeine in Java or ristretto in Go start from it. LRU is the default because it is cheap and most reads favour recent data.

    

    

      
Where you meet LFU

      
Redis with allkeys-lfu, which keeps a small counter per key that slowly decays. Use it when a backfill or a report scans many keys once and would flush the hot set. Adaptive replacement cache (ARC) keeps both lists and moves room to whichever one is winning.
