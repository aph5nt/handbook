Context engineering: choose what fills the window

The context window is the model's whole working memory for one call. Context engineering decides what goes in and in what order: instructions, the tools for this task, retrieved facts, recent turns, and the question. Watch a window get filled on purpose. Then switch tabs to see a window filled by habit.

Where you meet it

      
Claude Code loads skills only when their description matches, and AGENTS.md always. RAG pipelines choose the top chunks, not all of them. Tool search loads tool definitions on demand instead of hundreds at once.

    

    

      
The practical choice

      
Treat the window as a budget. Put stable parts first so they cache. Load tools and skills on demand. Retrieve a few cited chunks, not many. Keep pinned facts outside summaries. Put the question last. Measure answer quality when you add or remove a part.
