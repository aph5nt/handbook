Where you meet it

      
Cloudflare runs CDN (content delivery network), WAF (web application firewall), DNS and Workers on every server in more than 300 cities. Fastly, Akamai and AWS CloudFront are its rivals. The 2019 outage is a classic story of global config push and regex backtracking.

    

    

      
The choice you make

      
Treat a config change like a code deploy: canary, then a staged rollout with automatic rollback. Use a regex engine with linear time, such as RE2 or Rust's regex, for any pattern applied to user input. Keep a global kill switch per feature.
