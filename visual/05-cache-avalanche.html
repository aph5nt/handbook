Cache avalanche: many keys, or the whole cache, at once

A stampede is many misses on one key. An avalanche is misses on many keys at once. Press Next and watch twenty keys set at 09:00 all expire at 10:00. Then switch tabs and lose the Redis node itself.

Where you meet it

      
Warm-up jobs and batches that set many keys at once. A shared Redis without a replica. Any system where the database was sized for the cache misses, not for the full read load.

    

    

      
The practical choice

      
Jitter every TTL. Run the cache with replicas: Redis Sentinel or Redis Cluster. Put a rate limit or circuit breaker in front of the database, and serve stale copies while it recovers. Load-test with the cache off once.
