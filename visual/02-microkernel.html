Microkernel architecture

The indexer's exchange decoder has a small core that walks swap logs. Each exchange is a plug-in adapter named in a registry file. A new exchange is a new plug-in and one registry row, with the core untouched. Press Next.

Where you meet it: a DEX decoder

      
Each exchange is an adapter, and a registry file says which factory uses which adapter. The practical choice: ship the registry and the binary together, and check one against the other before every roll.

    

    

      
Where you meet it: editors and browsers

      
VS Code extensions, Eclipse plug-ins, browser extensions and Claude Code skills are microkernels. The host stays small, and a contract (an API, a manifest) lets others add features.
