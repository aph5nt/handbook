Where you meet sharding

      
Akka and Akka.NET Cluster Sharding, Orleans grain placement, Kafka partitions assigned to consumers. In the IoT backend, device actors were sharded by device id across the ingest nodes. Pick a key with many values and even traffic, and about ten shards per node so a move is small.

    

    

      
Where you meet split brain

      
Any cluster that decides membership by itself: Akka clusters, Elasticsearch, a database with automatic failover. Configure a split brain resolver (keep majority, keep oldest, keep referee). Run an odd number of nodes. Never down a node only because a timeout passed.
