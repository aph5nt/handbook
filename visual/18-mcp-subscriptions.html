Where you meet it

      
A freshness indicator that follows the chain head. A schema that gains new labels, so the host refreshes the context it attached. A stateless server offers no subscriptions: the host polls.

    

    

      
The practical choice

      
Coalesce updates on the server. Unsubscribe when the view closes. Keep the notice small and let the host read.
