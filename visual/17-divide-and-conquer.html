Divide and conquer: merge sort

A day of transfer amounts must be sorted. Merge sort splits the list in half until each piece is one number, then merges sorted pieces back up. Each level does one pass, and there are only log₂ n levels.

Where you meet divide and conquer

      
Merge sort, quicksort, binary search and the fast Fourier transform. A Go EVM indexer splits a block range into pieces for parallel workers: divide without a combine. MapReduce and Spark split, compute per piece, then reduce.

    

    

      
The choice you make

      
Split evenly, so there are log n levels. Keep the combine linear. Run independent parts in parallel. Accept merge sort's O(n) extra memory in exchange for a guaranteed O(n log n) and stability.
