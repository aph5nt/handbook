Where you meet it: apps with a user

      
"Sign in with Google" and every modern web, mobile and single-page app. PKCE (Proof Key for Code Exchange) is now used even by apps that also have a client secret. The old implicit flow, which put the token in the URL, is retired.

    

    

      
Where you meet the other flows

      
Service to service: client credentials, no user and no browser. A command line tool or a TV: device code. The tool prints a URL and a short code, the user approves in any browser, and the tool polls until the token arrives.
