Where you meet it

      
An EVM decoder memoizes token decimals, contract ABIs (the description of a contract's functions) and event signatures. Dynamic programming memoizes subproblems. React's useMemo keeps a value until its inputs change.

    

    

      
The practical choice

      
Memoize only pure functions. When a result depends on time or state, put that input into the arguments, such as the block number. Bound the map with LRU so it cannot grow forever.
