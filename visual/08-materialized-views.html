Where you meet it

      
StarRocks async materialized views with automatic rewrite for dashboards over swaps. PostgreSQL REFRESH MATERIALIZED VIEW CONCURRENTLY, with no automatic rewrite. BigQuery materialized views, which cut bytes scanned and the bill.

    

    

      
The practical choice

      
Build a view for a hot, repeated aggregate. Refresh it per partition, set a staleness limit, store bitmaps or HLL for distinct counts, and confirm the rewrite in EXPLAIN.
