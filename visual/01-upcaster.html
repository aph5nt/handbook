Upcaster: upgrade old events when they are read

Transfer events were written in three shapes over the years. The projector knows only the newest. Press Next to watch an old event stop the projection, and the upcasters that fix it without touching history.

Where you meet it

      
Event-sourced systems such as Axon Framework, which has upcasters built in. Kafka topics whose schema evolves, with readers that upgrade old records. A blockchain indexer whose decoder changes: the chain is never rewritten, the reading is.

    

    

      
The practical choice

      
Version every event from the first day. Write one small upcaster per version step, with a test using a real old event. Keep upcasters pure: no lookups, no clock. When the chain grows long, replay into a new stream and retire it.
