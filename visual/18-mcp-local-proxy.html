Where you meet it

      
The Chain Insights proxy: wallet, config and cache stay local, the graph stays remote. One place enforces answer rules and paging for every host.

    

    

      
The practical choice

      
Put personal state and light helpers in the proxy. Keep heavy data remote. Fetch lookup data at run time from git, with a packaged copy as the fallback.
