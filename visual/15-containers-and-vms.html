Where you meet it: every service

      
Every platform service runs as a container on Kubernetes. A Go service ships from a two-stage build: compile in a fat image, copy one binary onto a tiny base.

    

    

      
Where you meet it: a test sandbox

      
A command line tool is tested in a throwaway container with an empty home folder. The test can never write into the real wallet on the workstation.
