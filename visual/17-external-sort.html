External sort

A year of transfers, 500 GB, must be sorted on a machine with 64 GB of memory. Here the same thing at toy size: 12 numbers on disk, room for 4 in memory. Sort runs that fit, then merge them all in one pass.

Where you meet external sorts

      
A database ORDER BY, GROUP BY or sort-merge join that spills to disk. Spark and Hadoop shuffles sort and spill runs, then merge them. The Unix sort command does it with temporary files.

    

    

      
The choices you make

      
Make runs as big as memory allows. Read every run through a large buffer so the disk sees long sequential reads. Keep the number of runs below what one merge can buffer, so one merge pass is enough.
