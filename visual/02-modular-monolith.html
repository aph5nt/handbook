Where you meet it: a Go indexer

      
Each module is a Go package under internal/, so the compiler refuses an import from outside its tree. An import lint and one schema per module close the remaining gaps. This is the default for a new product with one or two teams.

    

    

      
Where you meet it: .NET and others

      
In .NET each module is a separate project with no cross references. In Java, modules or an architecture test do the same job. The practical choice: make the build fail on a forbidden import, not a reviewer.
