Where you meet it

      
Every web front end. Bundlers such as Vite and webpack hash file names for exactly this reason. The back/forward cache keeps whole pages for the back button. A service worker can add its own cache under the site's code.

    

    

      
The practical choice

      
Static files: hashed names and a max-age of a year with immutable. The HTML page: no-cache with an ETag. Telling users to clear their cache means the headers are wrong.
