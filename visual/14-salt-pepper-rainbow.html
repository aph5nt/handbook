Where you meet salts

      
Every password store. argon2id and bcrypt make a random salt per user and store it inside the hash string for you.

    

    

      
Where you meet peppers

      
High-value stores: a pepper from the vault or a hardware module, so a database dump alone is useless. API keys need neither: they are long and random already.
