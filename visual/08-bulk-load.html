Where you meet it

      
The Go indexer: Stream Load with the label <table>-page-<id>. PostgreSQL backfills: COPY, with indexes created after the load. Snowflake Snowpipe or StarRocks pipes for files that land continuously.

    

    

      
The practical choice

      
A bulk protocol for pages, files for history, never per-row inserts. Label every load so a retry is refused instead of doubled. Size loads under the timeout, one per table per page.
