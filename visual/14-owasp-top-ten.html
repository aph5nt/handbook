Entry (2021)The question to ask

      
A01 Broken access controlCan a user reach another user's data by changing an id?

      
A02 Cryptographic failuresIs it encrypted in transit and at rest, and are passwords slow-hashed?

      
A03 InjectionIs every input a parameter, never pasted into code?

      
A05 Security misconfigurationAre defaults, debug pages and open buckets closed?

      
A06 and A08 Components and integrityAre dependencies pinned, scanned and signed?

      
A10 SSRFDoes the server fetch any URL a user gives?
