Kubernetes objects

A balance API must run as three copies behind api.example. You never start a pod by hand. You declare objects, and Kubernetes keeps the cluster equal to them. Press Next and watch a pod die and come back, then a new version roll out.

Where you meet it: a stateless API

      
A query API is a Deployment of three pods behind a Service and a Traefik ingress. Readiness checks the database. Liveness checks only the process. A Horizontal Pod Autoscaler adds pods on CPU.

    

    

      
Where you meet it: state and jobs

      
A StarRocks warehouse is a StatefulSet: each pod keeps its name and its own volume claim. An indexer is one pod with a checkpoint, never autoscaled. A re-index from block 1 is a Job, a nightly partition move a CronJob.
