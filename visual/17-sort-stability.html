Where stability matters

      
Reports grouped by one column and ordered by another. A table header click that should keep the earlier order among ties. Radix sort, where every digit pass must be stable.

    

    

      
The choice you make

      
Go: sort.SliceStable, not sort.Slice. C++: std::stable_sort. Python sorted and Java object sorts are stable. In SQL, write ORDER BY address, block: SQL promises no order among ties.

Interview line"A stable sort keeps equal keys in their input order, so sorting in passes works and ties never scramble. Merge sort and Timsort are stable, quicksort is not, and when in doubt I add a tie-breaker key."
