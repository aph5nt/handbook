Recursion and the call stack

Compute fact(4), which is 4 × 3 × 2 × 1 = 24. Each call waits on a smaller call. The waiting calls pile up as frames on the call stack. Watch them push down to the base case, then pop back up carrying the answer.

Where recursion fits

      
Trees with a few levels: a tree of agent skills and their sub-skills, a JSON document, a parser walking nested brackets. The depth is bounded by how deep the nesting goes, and the code reads like the definition.

    

    

      
Where you use a loop instead

      
A transfer chain walked hop by hop can be a hundred thousand hops long. Python stops near 1,000 frames by default. Python, Java and Go do not reuse frames for tail calls. Use a loop with an explicit stack or queue.
