Where you meet it

      
Structured output in the Claude, OpenAI and Gemini APIs, and grammar or JSON-schema modes in self-hosted servers such as vLLM and llama.cpp. Tool call arguments use the same idea, so a call never fails on malformed JSON.

    

    

      
The practical choice

      
Use an enum for labels and a schema for records that code reads next. Always include an "unknown" or "not found" value, so the model is never forced into a wrong one. Check the values against the data after parsing.
