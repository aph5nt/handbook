Where you meet it

      
Date filters on timestamps: always a half-open range. Case-insensitive email: store it lower-cased or index lower(email). StarRocks partition pruning: the partition column must be bare.

    

    

      
The practical choice

      
Move functions and arithmetic to the constant side, match parameter types to column types, split OR into a UNION, and build an expression index when the function must stay.
