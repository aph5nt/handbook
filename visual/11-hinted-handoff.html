Where you meet it

      
Cassandra and ScyllaDB run hinted handoff by default with a hint window you can tune. Cassandra's default window is three hours. Their repair command compares Merkle trees between copies and streams only the ranges that differ.

    

    

      
The choice you make

      
Treat hints as the fast path, not the only repair. After a node was down longer than the window, run a repair before trusting its reads. The same idea fits any stand-in that buffers for a missing peer.
