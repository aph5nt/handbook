Where you meet passivation

      
Akka Cluster Sharding passivates idle entities after a timeout. Orleans deactivates idle grains the same way. Devices, sessions and carts have long quiet periods, so only the few that are busy right now need memory.

    

    

      
The choice you make

      
Passivate by idle time, such as two minutes, and persist state so a restart is cheap. Turn on remember entities only for the few entities that must run without a message: a timer per device, a long workflow waiting for a deadline.
