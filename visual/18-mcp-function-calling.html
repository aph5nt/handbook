Where you meet it

      
One app with a few tools in the same process: function calling alone. Tools shared across hosts or teams: MCP on top. Debugging a bad tool choice: read the schema the model actually received.

    

    

      
The practical choice

      
Write the MCP description as if it were the function-calling description, because it is. Keep tools few and intent-level.
