Conditional requests and HTTP caching

Thousands of browsers show pool 42. Between them and the pool API sits a CDN (Content Delivery Network) cache. Press Next and watch how few requests reach the API, and what goes wrong when a personal answer is cached as public.

Where you meet it: public reads

      
Pool metadata, token lists and docs pages behind a CDN: public, max-age, plus an ETag for cheap revalidation.

    

    

      
Where you meet it: browser apps

      
304 keeps repeat page loads cheap. Anything per user is private or no-store.
