Where you meet it: a shared warehouse table

      
The indexer owns the swap facts. The contract names columns, types, units, keys and freshness. The producer's tests check it, so a breaking change fails before merge.

    

    

      
Where you meet it: streams

      
A Kafka topic with a schema registry refuses an Avro schema that breaks compatibility. That is a data contract enforced at write time, per topic.
