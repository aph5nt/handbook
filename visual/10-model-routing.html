Model routing: the cheapest model that can do it

An agent serves two kinds of questions: many labels and lookups, a few full fund traces. Press Next and watch a router send each one to the cheapest model that can do it, and escalate when a check fails. The second tab shows when cheap is not cheap.

Where you meet it

      
A Claude Code harness where a small model picks which skill to load, then the big model runs with only that skill. Address labels at volume on a small or distilled model, fund traces on the big model. Cost reviews from traces, with the escalation rate per route.

    

    

      
The practical choice

      
Route on evidence from traces, not on a guess about difficulty. Always check a cheap answer before trusting it: schema valid, identifiers real, tests pass. Watch the escalation rate: when it climbs, the cascade can cost more than the big model alone.
