Where you meet it

      
Agents and MCP (Model Context Protocol) tool servers: tools run with the user's scope, never a powerful shared key. Backends calling downstream APIs with the user's token.

    

    

      
The classic shape

      
A shared service account with the union of everyone's rights. Through it, every user has every right any user has.
