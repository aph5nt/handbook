Where you meet it

      
Aggregates read by many dashboards: daily volume per pool from robinhood.core_dex_swaps. Snowflake, BigQuery and StarRocks all have a query result cache. Postgres has materialized views you refresh yourself.

    

    

      
The practical choice

      
When the expensive thing is an aggregate and the readers speak SQL, use a materialized view, not an application cache, and name its refresh interval next to it. For repeated identical dashboard queries, keep times fixed in the SQL so the result cache can work.
