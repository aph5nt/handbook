Where you meet it

      
Debezium reads the MySQL binlog and the Postgres WAL (write-ahead log) and publishes to Kafka. LinkedIn's first version was a system called Databus. The outbox pattern is the hand-made cousin: write the event to an outbox table in the same transaction, and let CDC publish it.

    

    

      
The same idea at home

      
An indexer writes chain facts to a warehouse, and a graph sync reads them later by block height. The table plays the log, so the graph never needs a second write path from the indexer.
